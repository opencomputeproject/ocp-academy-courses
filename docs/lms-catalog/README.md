# LMS catalog fields

Formal LMS titles and descriptions are maintained with their complete English
course sources, separately from maintenance README documentation. Each course
has a full formal title, a short description of at most 130 characters, and a
long description with an overview, overall learner duration, and module summaries.
Every summary starts on the line after its bold module title and duration.

Short descriptions are optional in the LMS; the repository provides them for
every course so all three fields are available when preparing a catalog entry.

Durations are learner-time estimates, including the relevant media, reading,
knowledge checks, and activities; they are not narration runtimes. Existing
course-level estimates are preserved. Where a course had no module estimates,
the catalog allocates its recorded total across the authored modules.
For SST, the catalog allocates the recorded 80-minute overall estimate as five
16-minute modules; the existing internal module-planning budgets (82 minutes
in total) are unchanged. Diablo 400 retains a 35-minute core path and a
15-minute optional module, or 50 minutes including both paths. Optional full
Summit recordings remain excluded from the existing FCSA estimate.

The Open Chiplet Economy and FCSA copy was approved on 26 October 2026;
Distributed AI Infrastructure was prepared for delivery on 2 November 2026.
Existing structured metadata is preserved. Earlier upload copy for Grid
Disturbance Performance, Project Brazos, Open Data Center for AI, and SUE-T
has been carried into the current structured format; their original files
link to the canonical exports.

Edit each course's `course.json.lms_catalog`, then regenerate and check its
`lms-catalog.json` and `lms-catalog.md` with
`skills/academy-wizard/scripts/course_delivery_summary.py <course.json> --write`
and `--check`. Packaging exports matching JSON, Markdown, and HTML files beside
the ZIP. See the [metadata contract](../../skills/academy-wizard/references/lms_catalog.md).
