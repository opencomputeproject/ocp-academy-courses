# pronunciation: OCP -> O C P; POI -> point of interconnection; PFAPR -> post-fault active power recovery; p.u. -> per unit; PSU -> P S U; UPS -> U P S; VFD -> V F D; OEM -> O E M; SVC -> S V C; E-STATCOM -> E statcom.

The recovery rule has a scope, a trigger, a target, and a time limit. The scope is the computational load for a qualifying low-voltage event in Table one. The trigger is point-of-interconnection voltage returning to the normal band, from zero point nine zero through one point one zero per unit, including both endpoints.

The target is ninety percent of the pre-fault load. The allowed time is two seconds from that voltage return. Pre-fault means the computational active-power baseline before the disturbance, not the reduced power during the sag and not the eventual cooling restart level.

Starting the clock at fault onset changes the meaning of the requirement. Starting it only after some later internal process completes also changes the meaning. Anchor the assessment to the normal-voltage return condition stated in the table.

The endpoint requirement does not prescribe one exact ramp shape. An illustrative straight-line recovery is useful for teaching, but it must not be presented as a mandated control trajectory. A facility's actual response depends on its equipment and control design.

In a review, label the voltage trace and the computational-power trace on the same time base. Mark the normal-band return, calculate the ninety-percent threshold, and place the two-second deadline. Those three annotations make the recovery claim inspectable and help expose any mismatch in the baseline or timing assumptions.
