Table one's footnote is part of the requirement, not an optional comment. It says that for sags or swells outside the specified magnitude and duration limits, computing loads are allowed to transfer to backup with no expectation on return timing or magnitude under this specification.

That changes how you interpret a long or severe event. Don't first acknowledge that an event exceeded the envelope and then automatically impose the same two-second recovery promise that belongs to the qualifying low-voltage rows.

For example, the earlier zero point three zero per-unit event lasting zero point two zero seconds exceeded its band's fifteen-hundredths-of-a-second minimum. The footnote provides the relevant out-of-envelope treatment. This does not require the equipment to transfer; it describes the permission and the absence of a specified return commitment in that circumstance.

The phrase under this specification matters. A particular project may have other agreed requirements or operating arrangements. This course does not decide those obligations or substitute for the project's actual interconnection agreement.

Before assessing a recovery trace, therefore, ask the qualification question first. Is this the kind of event for which the table makes the recovery commitment? Only then calculate the target and time. Applying an exact numerical test outside its stated scope produces a misleading result, even if the arithmetic itself is correct.
