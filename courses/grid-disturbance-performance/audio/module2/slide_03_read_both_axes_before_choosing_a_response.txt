Per-unit voltage expresses the measured voltage relative to its nominal value. One per unit means nominal voltage. Zero point eight per unit means eighty percent of nominal. This normalization lets us discuss the envelope without selecting one specific connection voltage.

The second quantity is time. Table one gives the minimum ride-through time before backup transfer is allowed for each voltage band.

The required time changes with the magnitude of the disturbance. A shallow sag and a very deep sag cannot be evaluated using the same duration.

Read both dimensions before choosing the power behavior. First locate the voltage band using its exact lower and upper boundaries. Next find the minimum ride-through time. Then read the behavior and recovery columns belonging to that same row. Don't take the duration from one row and the power permission from another.

Our worked examples hold voltage at a constant depth for a stated duration. That makes the band classification explicit. Real faults may move through multiple voltage levels or include reclosing. The source does not give a complete universal algorithm for combining those histories, so those details remain part of project coordination.

Use voltage to choose the band. Then compare the event duration with that band's minimum time. Read the power behavior from the same row. Keeping those three steps together makes the response decision clear.
