# pronunciation: OCP -> O C P; POI -> point of interconnection; PFAPR -> post-fault active power recovery; p.u. -> per unit; PSU -> P S U; UPS -> U P S; VFD -> V F D; OEM -> O E M; SVC -> S V C; E-STATCOM -> E statcom.

Traditional large-load interconnection work already addressed important questions. Could the generation and transmission system serve the requested capacity? Were protection and control coordinated? Did the facility satisfy applicable power-quality and power-factor expectations? Some utilities also applied load-shedding requirements.

The growth of large, dynamic computing loads adds another concern: how those loads behave together during a disturbance. Utilities need a credible picture of the voltage response, the resulting demand change, and the recovery that follows. A connection agreement based only on steady-state capacity cannot fully describe that behavior.

The O C P document brings the discussion to a common baseline for computational-load disturbance performance. Its comparison figures show that regional proposals differ. Those figures explain the context, but the O C P values we teach come from its own Table one.

Keep the status of each statement clear. This course explains the O C P specification and its proposed implementation approach. It doesn't establish which requirements a particular utility has adopted for a particular project. That application still belongs in the interconnection discussion.

The useful outcome is a shared vocabulary and a reproducible way to reason through a fault. Instead of saying that a facility can ride through, specify the voltage band, duration, allowed grid-power behavior, and recovery obligation that make the statement meaningful.
