A medium-voltage uninterruptible power supply is another architecture discussed in the specification. This medium-voltage U P S uses an in-line, double-conversion arrangement. Stored energy and controls may help the computational load achieve the required disturbance response.

But stored energy alone does not establish performance. The hardware, firmware, power path, and recovery controls must work together. The complete system needs evidence that it can meet the interface requirements.

For an existing facility, start with the physical constraints. Is suitable space available? Can the electrical and control interconnections be reached? Would construction require intrusive changes to a running site?

Then consider cost and disruption. The specification judges many medium-voltage U P S retrofits to be too costly and disruptive to be practical. This is an implementation concern. It does not mean the architecture can never be useful.

A new facility may have different options because space, connections, and construction can be planned early. A retrofit has to work around the equipment and operations already in place.

Evaluate the actual architecture and the actual site. Ask for evidence of the required response. A block labeled stored energy is only one part of that assessment.
