# Open Rack: Kiến trúc, nguồn điện, làm mát và triển khai

This `vi-VN` edition follows the four modules of the [Open Rack course](../../README.md). [Read the localized course description and module outline](lms-catalog.md).

The slide definitions are in [course.json](course.json), the narration scripts in [audio](audio/), and the teaching visuals in [figures](figures/). To rebuild with approved recordings, follow the [course build instructions](../../README.md#languages-and-earlier-editions) using locale `vi-VN`. The [release record](localization/release.json) identifies the scripts, recordings, and delivered package by checksum.
