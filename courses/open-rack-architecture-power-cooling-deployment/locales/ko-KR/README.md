# Open Rack: 아키텍처, 전력, 냉각 및 구축

This `ko-KR` edition follows the four modules of the [Open Rack course](../../README.md). [Read the localized course description and module outline](lms-catalog.md).

The slide definitions are in [course.json](course.json), the narration scripts in [audio](audio/), and the teaching visuals in [figures](figures/). To rebuild with approved recordings, follow the [course build instructions](../../README.md#languages-and-earlier-editions) using locale `ko-KR`. The [release record](localization/release.json) identifies the scripts, recordings, and delivered package by checksum.
