# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
The metrics in this module turn link state into a decision.

Signal-quality measurements help locate the weak interface or lane. Error, recovery, and uptime data show whether that weakness is affecting service. Environmental and identity fields connect the evidence to the physical module.

The health score takes the minimum of the supported category scores for the selected host or media side. The lowest-category bitmap identifies every tied contributor. Counter masks and configured thresholds explain how that summary was calculated.

Autonomous shutdown is a separate configured response. It starts disabled after reset, and a triggered shutdown leaves fault and event evidence. Do not confuse a low score with proof that shutdown was enabled or occurred.

The practical test is whether the evidence narrows the next step. Does it suggest optical inspection, electrical-margin investigation, thermal checks, firmware review, or continued monitoring? The next module shows how software requests and preserves the information behind those choices.
