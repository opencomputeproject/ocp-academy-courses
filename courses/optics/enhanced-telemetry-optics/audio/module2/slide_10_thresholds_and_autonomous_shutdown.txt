# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
Configuration changes how the module evaluates a condition and how it can respond. Keep those two choices separate.

Threshold control, command eight thousand four hex, reads or sets two score boundaries for feck-bin level, pre-feck B E R, S N R, and eye height. The boundaries divide the eighty, sixty, and forty score bands.

The comparison direction depends on the metric. Higher B E R is worse. Higher S N R and eye height are better. Threshold settings apply to the selected module, and event indicators or status flags are not programmable score-threshold categories through this command.

Autonomous shutdown uses command eight thousand five hex. It is disabled by default after module reset or power reset. When enabled and triggered by an unhealthy condition, it transitions the module to a fault state.

The module reports fault cause twenty-six hex and records event zero zero zero C hex. The event details identify the affected side, datapath port, category, and metric value. That evidence helps distinguish a configured response from an unexplained link drop.

Before qualification or incident analysis, read back the effective thresholds and shutdown state. Configuration is part of the evidence, not background information.
