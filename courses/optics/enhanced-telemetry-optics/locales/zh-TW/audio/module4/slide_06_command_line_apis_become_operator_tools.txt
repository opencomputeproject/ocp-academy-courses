# TTS note: pronounce FEC as "feck"; preserve official technical acronyms.
主機 SDK 將通用模組介面轉化為維運工作流程。規範描述了 SONiC 實現和一組命令列 API 類別。

本地與遠端 CMIS 存取提供暫存器狀態。遙測下載顯示所選端點、介面側與埠的測量值。事件工具以可讀形式獲取近期歷史，控制遲滯，並且只在明確需要時清除歷史。

韌體工具使用相應命令族和經過檢查的生命週期各階段的結果，處理本地或遠端維護。模組時間控制提供比較記錄所需的時間參考，鏈路評分顯示則提供簡明的入口，供維運人員深入檢視底層證據。

資格驗證和診斷工具還需要能力發現、計數器遮罩控制、臨界值控制與關閉狀態核實。即使某個使用者介面採用不同的功能分組，這些操作仍由底層命令定義。

要明確區分讀取與設定更改。獲取歷史、清除歷史，以及改變模組回應方式，是不同的操作。

實用的工具會在報告數值的同時，提供目標、支援能力、生效設定和命令結果。正是這些脈絡，使輸出在真實故障中值得信賴。
