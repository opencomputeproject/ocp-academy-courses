# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
導入準備とは、エビデンスを得る経路全体の動作を試験することです。

モジュールのテレメトリバージョン、対応コマンド、対応メトリクスを検出します。帯域内通信への対応とレーン確立を確認します。混在環境では、サードパーティーのパートナーとデータリンクが動作しても、リモートの高度テレメトリを利用できるとは限りません。

ローカルとリモートの要求を試験します。ブレイクアウト構成では、正しいパートナーとデータパスを含めて確認します。モジュール時刻を設定し、イベントをホストの測定値と照合できることを確認します。リセット、取り外し、再挿入を経ても履歴を保持します。

スコアのマスクと閾値を読み戻します。自律シャットダウンがリセット後は無効であることを確認し、設定後は意図した状態になっていることを確認します。有効にする場合は、応答を異常原因とイベントのエビデンスからどのように特定できるかを試験します。

ファームウェアの機能検出、転送、完了、実行、検証、コミット、中止処理を試験します。実行中のイメージの状態と、今後のリセット時の既定値を区別します。

最後に、実際のホストツールから、オペレーターがこのエビデンスを取得できることを確認します。重大なインシデントが起きる前に、チームがインターフェースを予測どおりに使用できる状態が、導入準備の整った状態です。
