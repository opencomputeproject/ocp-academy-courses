# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
ファームウェアの保守には、関連する2つの経路があります。標準のローカル操作は、CMIS 5.3のファームウェア管理コマンドを使用します。高度テレメトリ仕様は、8030hコマンド群によるリモートプロトコルを定義しています。

まず、対応機能を検出し、ファームウェア情報を確認します。リモート情報の応答では、イメージの有効性、現在実行中のイメージ、今後のリセット時の既定値としてコミットされたイメージが区別されます。

通常のリモート手順では、ダウンロードを開始し、データブロックを転送し、ダウンロードを完了して検証し、イメージを実行して、検証済みの実行中イメージをコミットします。開始済みのダウンロードを中止するコマンドもあります。

転送の成功とアクティベートの成功を同一視してはいけません。同様に、新しいイメージを実行しても、それだけで将来のリセット時の既定値になるわけではありません。これらは別の状態で、それぞれにコマンドの結果があります。

各段階で、選択したパートナー、イメージ情報、状態を記録します。これにより、保守作業を監査でき、最後のブロックを送っただけでソフトウェアが成功と判断することを防ぎます。
