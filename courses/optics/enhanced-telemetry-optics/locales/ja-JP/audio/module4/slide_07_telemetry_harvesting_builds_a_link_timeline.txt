# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
ホストソフトウェアセクションは重要な意図を示しています。すなわち、ホストが現在のリンク状態を継続的に収集し、リンク性能タイムラインを作成し、それをテレメトリサーバーにストリーミングしてファブリック全体のネットワークマップに集約できるということです。

この一文がコース全体をつなげています。単一のクエリが役立ちます。タイムラインの方が良いです。ファブリックマップはさらに優れており、オペレーターはスイッチ、モジュール、レーン、リモートエンドポイント、時間間で症状を比較できます。

タイムラインには、現在のメトリクス、イベントログ記録、リモートパートナーチェック、そして事前フェックB E Rやスイッチセルデス受信機での修正不可コードワードなどのホスト側の測定値を含めるべきです。これらの価値観が一致すると、トラブルシューティングは単独のアラームから証拠に基づく作業へと移行します。
タイムラインはスナップショットが見逃すパターンを明らかにし得ます。例えば、再リンク前の温度上昇や局所警報前のリモートエンドポイントのイベントは、調査を推測からシーケンス解析へと変えることがあります。
