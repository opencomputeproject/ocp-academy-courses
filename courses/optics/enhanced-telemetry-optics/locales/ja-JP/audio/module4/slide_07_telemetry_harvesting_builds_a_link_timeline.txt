# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
継続的な収集は、個別の測定値をリンク性能のタイムラインに変えます。ホストはそのタイムラインをテレメトリサーバーにストリーミングでき、オペレーターはファブリック全体の状況を構築できます。

時刻同期は、このエビデンスの経路の一部です。Get Module TimeとSet Module Timeは、コマンド0005hと0006hを使用します。協定世界時の1970年の開始を基準とするPOSIXエポックからの時間を、ナノ秒単位の64ビット値で表します。

高度テレメトリの定義は、これらのコマンドをリモート操作向けに拡張しています。ホストは、選択したリモートパートナーの時刻を照会できます。設定コマンドは、その対象フィールドの定義に従い、ローカルモジュール、またはローカルとリモートのポートを対象にできます。

タイムスタンプの単位だけで時計精度は決まりません。モジュールとホストの間でイベントを比較する前に、ソフトウェアが時刻基準を設定し、検証する必要があります。

タイムラインには、スイッチ自身の受信機の測定値であるpre-FEC BERと訂正不能コードワードも含まれます。モジュールのデータだけでは、すべての受信セグメントを網羅できません。

エンドポイントの識別情報、有効な時刻、現在のメトリクス、永続的なイベント記録がそろうことで、再リンクの前に温度が上がった場合と、リモート障害の後にローカルアラームが発生した場合を区別できます。
