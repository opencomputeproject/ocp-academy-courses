# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
このモジュールの終わりまでに、4つの運用部品を接続できるようになります。

まず、すべてのコマンド識別子を暗記することなく、ローカルおよびリモートのファームウェア管理について説明します。次に、オペレーターがリモートパートナーからの情報を求めても、ホストソフトウェアがローカルモジュールと通信する理由を説明します。

第三に、モジュールの動作を利用可能なコマンドに変換するAPIカテゴリを特定します:レジスタアクセス、テレメトリダウンロード、イベントログ、ファームウェア更新、エポックタイム、ヒステリシス、リンク評価。

最後に、テレメトリの収集とイベント履歴をファブリック全体の健康マップに接続します。そこでは、単なるプロトコル知識ではなく、展開準備の準備が進むコースになります。
目標を見直す際には、引き継ぎについて考えてみてください。モジュールデータはホストの出力となります。ホストの出力はオペレーターの行動となります。オペレーターの操作は繰り返し可能な展開プロセスに適合します。その繰り返し可能なプロセスが目標です。
