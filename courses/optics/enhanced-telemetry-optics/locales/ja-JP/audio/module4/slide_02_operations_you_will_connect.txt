# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
このモジュールでは、プロトコルの動作を、繰り返し実行できる運用に結び付けます。

まず、標準のローカルCMISファームウェアワークフローと、リモートの8030hコマンド群を区別します。イメージのダウンロード、実行、コミットが別の手順である理由を説明します。

次に、ホストの境界を説明します。ホストはI2Cでローカルモジュールと通信し、そのモジュールが帯域内通信でリモートパートナーのデータを取得します。

続いて、オペレーターに必要なツールのカテゴリを確認します。レジスタアクセス、テレメトリ、イベント履歴、ファームウェア保守、モジュール時刻、ヒステリシス、健全性評価です。

最後に、モジュールのタイムスタンプとホスト受信機の測定値を、同じエビデンスのタイムラインに結び付けます。インシデント時に導入環境を信頼して使う前に、機能、パートナーの識別情報、スコア設定、シャットダウンの既定値、ファームウェアの結果を検証します。

目標は、モジュールの測定値からホストの出力へ、ホストの出力からオペレーターの判断へ、そして判断から記録された行動へと、確実に情報を引き継ぐことです。
