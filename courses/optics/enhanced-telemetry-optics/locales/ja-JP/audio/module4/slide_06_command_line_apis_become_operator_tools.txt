# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
ホスト、SDKおよびコマンドラインAPIが、この仕様がオペレーターにとって有用になる部分です。仕様書には、現場のワークフローに直接対応するカテゴリが記載されています。

標準的なC M I Sアクセスはソフトウェアがローカルモジュールの状態を読み取ることを可能にします。リモートアクセスにより、ソフトウェアは遠方エンドポイントから標準データを抽出できます。テレメトリのダウンロードはローカルまたはリモートモジュールパラメータを公開します。イベントログコマンドは最近のイベントを読み取り、ログをクリアし、ヒステリシスを調整します。ファームウェアコマンドはローカルまたはリモートの更新ワークフローを管理します。

仕様にはエポックタイムやモジュールリンク評価表示も含まれています。これらのカテゴリーは、現在の価値、過去の出来事、時間の相関、そして簡潔な健康スコアという証拠の連鎖をつなぐため重要です。良いAPIは、そのチェーンを予選やインシデント時に使えるものにします。
APIのカテゴリは文書化やトレーニングにも対応すべきです。オペレーターはどのコマンドが現在のテレメトリを取得し、どのコマンドが最近のイベントを取得し、どのコマンドが履歴をクリアし、どのコマンドが動作を変更するかを知っておくべきです。
