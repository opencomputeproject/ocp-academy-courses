# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
このモジュールの終わりまでに、あなたは4つのことができるようになります。まず、ローカルのテレメトリクエリとリモートのクエリを区別し、コマンドフィールドを暗記する必要はありません。

次に、信号品質、誤り・訂正挙動、リカバリーカウンター、環境、モジュールコンテキストの主要な指標ファミリーを分類します。

第三に、リンクヘルススコアを最悪カテゴリービューとして説明します。この設計の選択は重要です。なぜなら、1つの悪いカテゴリが他のカテゴリが健全に見えても、リンクが運用上リスクを生む可能性があるからです。

最後に、サマリーフラグやマスクが監視システムをどのように実行可能に保つかを説明し、特に特定の展開で一部のカウンターを含めるか除外すべき点について説明します。
すべての分野を暗記する必要はありません。価値がどのカテゴリーに属し、どんな疑問に答えられるのか、どのようなフォローアップエビデンスを示唆しているのかを認識する必要があります。
