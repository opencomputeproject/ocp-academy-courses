# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
フラグとマスクがモデルを操作可能に保つ方法です。要約フラグは、ソフトウェアやオペレーターがメトリクスグループが閾値を超えたか、注目に値する状態に移行したかを認識するのに役立ちます。

マスクはチューニングを提供します。特定の運用モード、資格審査段階、統合コンテキストにおいて、特定のカウンターがリンク健康計算に影響を与えないようにする展開が決定されることがあります。マスクは展開時にフィールドの包含または除外を可能にしつつ、より広い構造を保つことができます。

バランスが大切です。生カウンターが多すぎるとノイズが発生します。要約しすぎると理由が隠れてしまいます。旗とマスクが中央に配置され、監視信号を意味のあるものに保つための簡潔な健康状態の表示です。
マスクは慎重に使うべきです。カウンターを除外することで誤報を減らすことができますが、有用な信号を消すことにもなります。展開では、なぜフィールドがマスクされているのか、そしてその選択をいつ再検討すべきかを記録すべきです。
