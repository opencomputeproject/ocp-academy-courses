# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
健康スコアについて話す前に、モジュールの基準状態が必要です。仕様は共通のC M I Sバンクゼロページ、構成およびステータスページ、V D Mページ、C D Bコマンドページ、C D Bペイロードページ、カスタムベンダーページを指しています。

このコースで重要なのは、すべてのフィールドの正確なページ番号ではありません。重要な点は、高度なテレメトリが構造化された管理インターフェースの上に配置されていることです。ホストは標準的な識別情報とステータス情報を取得し、高度なテレメトリ定義を用いてより深い信頼性の質問を行えます。

その層状がコースを実用的に保っています。詳細な地図がどこにあるかは知っているべきですが、最初のメンタルモデルはまずアイデンティティと状態、次に測定値、そして健康の解釈であるべきです。
ベースラインページはまた、ソフトウェアが文脈の誤読を避ける手段でもあります。ツールがテスト対象モジュールに対してテレメトリフィールドが利用可能、現在、または意味があると仮定する前に、識別情報、能力情報、状態情報を確認する必要があります。
