# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
このモジュールの指標は単なる長いリストではありません。リンク状態を行動に変える手段です。

品質指標は、弱い信号が電気的なもの、光学的なもの、回線側、ホスト側、またはレーン固有の信号かどうかを局所化するのに役立ちます。エラーと回復指標は、弱点が修正負荷、再リンク、または修正不可能な挙動を引き起こしているかを示します。環境分野やアイデンティティ分野は証拠を追跡可能にします。

リンクヘルススコアはその証拠を慎重に圧縮します。平均値ではなく最も弱いカテゴリを用います。なぜなら、単一の悪いフィールドがリンクの信頼性を失う原因になる可能性があるからです。この考え方がワークフロー層、すなわちホストソフトウェアがどのようにデータを要求、チェック、取得、ログ記録するかに備えます。
