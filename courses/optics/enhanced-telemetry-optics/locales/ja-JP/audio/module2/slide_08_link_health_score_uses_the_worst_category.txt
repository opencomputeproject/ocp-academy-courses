# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
健全性スコアは、対応が必要な測定結果を見失わないものでなければなりません。健全なフィールドと問題のある1つのフィールドを平均すると、問題を隠すことがあります。

仕様では、まず、対応する各カテゴリをその閾値に照らして評価します。定義されるカテゴリスコアは80、60、40です。そして、その最小値を、選択したホスト側またはメディア側の評価値とします。

ホスト側のカテゴリには、電気信号品質、pre-FEC BER、モジュールフラグ、有効にした場合の所定のカウンターが含まれます。メディア側のスコアには、MPI、光パワーフラグ、レーザーバイアスフラグなど、光に固有のエビデンスも含まれます。両側のカテゴリ一覧は同一ではありません。

アニメーションは、メディア側の一部のカテゴリを示しています。BERカテゴリが40に下がると、最小値もそれに従います。平均値は依然として良好に見えますが、これこそ仕様が避けている情報の欠落です。

テレメトリ応答には、最低評価カテゴリのビットマップも含まれます。複数のカテゴリが最小値で並ぶ場合は、複数のビットが設定されます。原因を1つと決め付けず、このビットマップと元の測定値を確認してください。

最後に、有効なカウンターマスクと閾値の設定を踏まえて結果を解釈します。スコアに意味があるのは、その設定とエンドポイントの情報が分かっている場合だけです。
