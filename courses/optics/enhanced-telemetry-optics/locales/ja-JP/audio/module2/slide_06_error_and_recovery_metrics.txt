# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
品質指標はマージンの状況を示しています。エラーとリカバリーの指標は、その差がサービスにどのように影響しているかを示しています。仕様には、事前B E R、feckビンヒストグラム、修正不可のコードワード、再リンク回数、信号の喪失、リンクの喪失、そして最後の新しいリンクアップ以降の稼働時間が含まれます。

これらの値は、ノイズがあっても修正されたリンクと、実際に切断・再取得しているリンクを区別するのに役立ちます。その区別はメンテナンス中に重要です。誤差パターンが修正された場合、トレンドの監視や資格確認の注意が必要になることがあります。繰り返される再リンクや修正不可能なコードワードは即時の隔離を必要とすることがあります。

最も強力なワークフローは両方の視点を組み合わせています。信号品質の証拠とサービス影響の証拠を一緒に持つ必要があります。なぜなら、その組み合わせは重症度と推定される場所を示すからです。
時間の次元はカウントと同じくらい重要です。単一の修正された誤りバースト、上昇傾向のヒストグラム、短いウィンドウ内で繰り返されるリリンクは、誤り指標の下で現れるものの異なる運用上の物語です。
