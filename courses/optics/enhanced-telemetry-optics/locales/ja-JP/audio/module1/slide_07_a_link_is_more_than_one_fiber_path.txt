# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
リンクは2つのモジュール間のファイバーだけではありません。スイッチとモジュールの電気接続、モジュール間の光接続、モジュールとサーバーの電気接続という、3つのインターフェース領域があります。

トラフィックは双方向に流れるため、仕様は方向ごとに6つのリンクセグメントを定義しています。各受信機が観測するのは、特定の入力信号です。ある受信機で結果が悪くても、それだけで送信機、ファイバー、電気インターフェースのどれが原因かが決まるわけではありません。

この区別が、モジュールのテレメトリとホスト受信機の測定値を組み合わせる理由です。スイッチも、自身のpre-FEC BERと訂正不能コードワードを記録します。リモートテレメトリにより、オペレーターがサーバーへ直接アクセスできない場合でも、対向側のモジュールを確認できます。

アニメーションでは、6方向を3つのインターフェース領域にまとめています。この見方で調査を整理し、該当する受信エンドポイントの測定値を比較してください。

症状が一致しない場合は、その不一致もエビデンスとして残します。ローカルのアラーム、リモートのイベント、ホスト側のエラーパターンは、同じ障害の異なる部分を示している可能性があります。セグメントの識別情報があってこそ、それらの観測が役立ちます。
