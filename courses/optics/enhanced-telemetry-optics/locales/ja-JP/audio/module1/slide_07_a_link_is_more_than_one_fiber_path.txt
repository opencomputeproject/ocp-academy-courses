# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
重要な転換点は、リンクを単なるファイバーパスとして考えるのをやめることです。ポイントツーポイントの図は接続を監視セグメントに分割します。一方の側面では、スイッチがローカルモジュールと電気的に通信しています。中央では、2つのモジュールが光学的に通信します。遠く側では、リモートモジュールがホストと電気的に通信しています。

そのセグメンテーションはデバッグ時に重要です。光信号が悪いことは、電気受信機の問題とは同じ意味ではありません。ローカルアラームが、原因が遠隔区画にある症状を報告している場合があります。

テレメトリモデルは、ホストソフトウェアを通じて全経路にわたる証拠を求める方法を提供します。各セグメントが一貫して測定・報告できるようになれば、オペレーターは本能的に部品を入れ替えるのではなく、劣化の所在を推測できるようになります。
このセグメントビューは、症状が一致しない場合にも役立ちます。ホストがある挙動を見、モジュールが別の挙動をログに記録し、遠隔パートナーが3つ目を示すことがあります。モデルは、単に責任を問うだけでなく、比較できる場所を提供します。
