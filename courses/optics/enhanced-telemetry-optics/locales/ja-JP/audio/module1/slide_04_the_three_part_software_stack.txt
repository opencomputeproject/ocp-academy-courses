# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
ソースドキュメントには準拠ソフトウェアシステムの3つのコンポーネントが記載されています。1つ目はトランシーバ自体です。ファームウェア、テレメトリメトリクス、イベントログ、そしてそれらの値を公開するために必要なコマンド動作です。

2つ目はホストソフトウェアで、通常はスイッチ上にあります。このレイヤーは、I二乗C上でローカルモジュールと通信し、ローカルまたはリモートのパートナーデータを要求し、モジュールの応答をオペレーターが使えるツールに変換します。

3つ目はテレメトリーサーバーソフトウェアです。仕様書では、テレメトリがファブリックレベルでコンパイル、要約、報告されることを期待していますが、すべてのオペレーターがどのようにサーバー側を構築するかは規定されていません。その境界線は重要です。このコースでは、共通のモジュールとホスト間のインターフェースを教えます。なぜなら、貢献が標準化する部分だからです。
その多層的な視点は責任感にも役立っています。トランシーバーは測定・保存できるものを所有します。ホストは、どのように尋ね、どのように提示するかを所有します。テレメトリサーバーは大規模運用環境全体でより広範な相関関係を持っています。
