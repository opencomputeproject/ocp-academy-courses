# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
高度光テレメトリでは、OCP Networking Projectが示す、光リンクの信頼性を支える共通の運用モデルを学びます。仕様の執筆者はCredoのChris Collins氏で、Cisco、Credo、Marvell、Oracleからのコミュニティのフィードバックへの謝辞が記されています。

コースは4つのパートで構成されています。まず、スイッチポート、トランシーバーモジュール、ファイバー経路、そしてベアメタルサーバーの内部にある場合もあるリモートエンドポイントにまたがる、可視性の不足を捉えます。

次に、信号品質、エラー、復旧動作、環境、識別情報を調べます。これらの測定値を、側ごとの健全性スコア、フラグ、カウンターマスク、設定によるモジュールの動作に結び付けます。

続いて、エビデンスを運ぶコマンド／応答のワークフローを追跡します。CDB、タイムスタンプ付きのイベントログ、リモートCMISレジスタへのアクセスを扱います。

最後に、テレメトリをファームウェア保守、ホストAPI、時刻同期、導入時の検証に結び付けます。この情報が、オペレーターによる問題箇所の特定と次の行動の選択に役立つか、という問いを常に意識してください。それが共通インターフェースの目的です。
