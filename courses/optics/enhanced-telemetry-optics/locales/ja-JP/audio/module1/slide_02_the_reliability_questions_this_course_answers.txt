# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
このコースは、OCPおよびOracleのボランティアによるコミュニティ貢献に基づいています。コースは4つのパートで構成されています。まず、光リンクがスイッチポート、トランシーバーモジュール、光ファイバー経路、そしてベアメタルサーバー内に設置される可能性のあるリモートエンドポイントにまたがる際に現れる可視性ギャップを枠付けます。

次に、リンク状態を実用的にするテレメトリのカテゴリ、すなわち光品質、電気品質、エラー、回復動作、温度、電力、管理コンテキストを解析します。

第三に、コマンド/応答ワークフローを見て、この情報をホストソフトウェアとモジュール間で移動させます。これにはC D B、イベントログ、リモートC M I Sアクセスが含まれます。

最後に、テレメトリモデルをファームウェア管理、ホストAPI、デプロイ準備と結びつけます。最終的には、バイトマップに縛られることなく動作モデルを説明できるようになるはずです。
モジュールを進める際に一つだけ覚えておいてください。この情報はオペレーターが次の行動をより早く決めるのに役立つでしょうか?もし答えがイエスなら、それは信頼性のワークフローに属します。
