# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
ステータスチェックこそが、コマンド/応答のワークフローを正直に保つものです。モジュールが忙しい場合もあります。コマンドは成功裏に完了することもあります。コマンドは失敗することもあります。ホストソフトウェアは応答を有効と扱う前に、どの状態を見ているかを知る必要があります。

そのため仕様にはC D Bコマンドステータスレジスタと完了インジケーターが含まれています。重要なのはコマンドを完成させることだけではありません。目的は、ホストの動作を再現可能にすることです。

信頼できるオペレーターツールは、テレメトリが準備完了であると推測してはなりません。コマンドをトリガーし、完了のポーリングを行い、失敗を明確に処理し、その後応答を取り戻すはずです。このソフトウェアの規律こそが、低レベルのモジュールの動作を信頼できる運用証拠とすることを可能にしています。
良好なステータス挙動は自動化も向上させます。スクリプトは安全に再試行、バックオフ、コマンド失敗の報告、または古いデータを提示する前に停止することができます。これが役立つツールとリスクの高い近道の違いです。
