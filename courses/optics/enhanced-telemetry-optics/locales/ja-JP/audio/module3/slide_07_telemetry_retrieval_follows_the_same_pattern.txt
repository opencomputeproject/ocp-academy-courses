# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
テレメトリのパターンが明確になると、テレメトリの検索は理解しやすくなります。ホストが要請を発行します。ローカルモジュールは関連するフィールドを収集または取得します。ホストはコマンドの状態を確認します。そして返信を読みます。

返信には健康スコア、モジュール識別子、リンクダウンカウンター、稼働時間、フラグ、品質指標、温度、電圧、受信電力、エラー挙動、feck情報が含まれます。正確なフィールドマップは仕様書に含まれますが、運用モデルは頭の中にあります。

一つの有用な考え方はこうです:コマンドはオペレーターのために一貫したスナップショットを集めます。散らばったフィールドを追いかけるのではなく、ワークフローはリンクヘルスの疑問に答えるために必要な証拠をパッケージ化します。
学習者にとって重要なのは再現性です。パターンを理解すれば、コマンド名やペイロードフィールドが変わっても、異なるオペレーターコマンドの背後にある同じ構造を認識できます。
