# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
現在のテレメトリはリンクの現在の様子を示しています。イベントログは、どうやってそこに来たのかを説明するのに役立ちます。

仕様書は不揮発性メモリにおけるイベントログを記述しています。また、32バイトのイベントログエントリを一意のシーケンス値、タイムスタンプフィールド、イベント識別子、詳細フィールドも記述します。最小のシーケンス値は最も古いレコードを示し、シーケンスはラップ可能です。

この構造は、モジュールが移動、リセット、または事後に点検される際に重要です。ログが順序、時間、イベントタイプ、関連詳細を保持していれば、オペレーターはダッシュボードに最初に届いたアラームに頼る代わりに故障のストーリーを再構築できます。

教訓はシンプルです:出来事の歴史は一時的な症状を証拠に変えます。
イベント記録はベンダーやオペレーターの会話中にも役立ちます。問題がいつ発生したかを議論する代わりに、チームは順序付けられた記録、タイムスタンプ、詳細をホストログやメンテナンスウィンドウと比較できます。
