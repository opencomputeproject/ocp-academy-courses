# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
C D Bはホストとモジュールにコマンド/応答パターンを与えます。仕様書は典型的なシーケンスを4段階で記述しています。

まず、ホストが必要なヘッダーフィールドとペイロードを入力してコマンドメッセージを準備します。次に、メッセージを適切な場所に書き込むことでコマンドを発動します。第三に、C D Bステータスレジスタをポーリングして進捗を監視します。第四に、コマンドが完成すると、応答ヘッダーとペイロードを取得します。

このパターンがこのモジュールの基盤となっています。ホストがテレメトリを取得している場合でも、イベントログレコードの要求であれ、あるいはより広いペイロード領域を使っている場合でも、操作の仕組みは同じです:リクエストを書き、トリガーし、状態を確認し、応答を読み取るだけです。
この4つのステップは、ソフトウェアの誤動作時のトラブルシューティングも容易にします。コマンドが正しく形成されたか、トリガーされたか、ステータスが読み取られたか、応答が完了に合致したかを尋ねることができます。
