# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
リモートアクセスは同じモデルを遠端エンドポイントまで拡張します。ホストはリモートモジュールへの別の直接管理パスを開くわけではありません。ローカル準拠モジュールに問い合わせ、ローカルモジュールがリモートデータをインバンドで取得します。

概念的には、2つの有用なアクセスモードがあります。バイトアクセスは標的とされています。ソフトウェアが狭いフィールドや狭い範囲を必要とする場合に適しています。ページアクセスはより広範囲に広がっています。これはより大きなページ指向のスナップショットを取得します。

これは操作において強力であり、スイッチホストが光リンクの両端を検査できる手段を提供します。オペレーターは物理的にリモートエンドポイントにアクセスすることなく、ローカルとリモートの証拠を比較できます。
物理的なアクセスが遅い、または利用できない場合にもリモートアクセスが役立ちます。誰かを設置したりモジュールを交換したりする前に、オペレーターは遠方の証拠を集め、その行動が正当化されるかどうかを判断できます。
