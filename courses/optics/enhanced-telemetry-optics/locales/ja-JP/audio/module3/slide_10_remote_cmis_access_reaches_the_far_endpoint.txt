# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
リモートCMISアクセスは、読み取りと書き込みの両方に対応します。ホストはローカルの準拠モジュールに要求を送り、そのモジュールが帯域内インターフェースで選択したリモートパートナーにアクセスします。

バイトアクセスはコマンド8020hを使用します。リモートポート、バンク、ページ、アドレス、操作、長さを選択します。ローカルペイロードで扱う、狭いレジスタ範囲の操作に適しています。

ページアクセスは、コマンド8021hと拡張ペイロードを使用します。複数の小さな範囲ではなく、リモートのページ全体を読み書きする場合に適しています。

診断では、読み取りによってエビデンスを取得します。書き込みはリモートの状態を変えるため、ツールは操作と宛先を明確に示し、導入環境の保守管理に従わなければなりません。

どちらのモードでも、結果を信頼する前に、コマンドの完了状態と失敗状態を確認します。選択したパートナーとバンク／ページの情報を出力に残します。

この仕組みは、1つのローカル管理インターフェースから対向側を可視化します。同時に、対象を慎重に選ぶことが不可欠です。特にブレイクアウト構成では、要求自体が正しくても、誤ったパートナーを指定している可能性があります。
