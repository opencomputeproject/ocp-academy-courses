# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
イベントログは有用な詳細が必要ですが、同時に制御も必要です。ノイズの多いリンクは繰り返し閾値を越えることがあります。ヒステリシスがなければ、ログは重複したエントリーで埋められ、実際の出来事の順序が見えにくくなります。

仕様には、リンクアップ、リンクダウン、信号損失、リンク損失、M P I閾値、S N R閾値、プレフェックS N R閾値、feckヒストグラム閾値、補正不可feck、モジュール温度、受信電力などの閾値駆動イベントが含まれます。また、イベントヒステリシスの読み書きに対応したホストAPIも記載されており、仕様のデフォルト値は10秒です。

最終リリースでは、その値を公開仕様と照合する必要があります。このコンセプトは安定的です。イベントの挙動を調整し、ログがノイズではなく信号を保存するようにします。
ヒステリシスは失敗を隠すためのものではありません。それは読みやすい失敗の物語を守ることです。同じ振動を何度も記録するログは、根本原因の特定を難しくし、簡単になるどころか難しくします。
