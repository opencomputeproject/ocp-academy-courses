# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
このモジュールはテレメトリをワークフローに変換します。C D Bはホストソフトウェアの繰り返し可能なコマンド/応答シーケンス:準備、トリガー、ポール、リトリーブです。ページ9Fhとペイロードページはその交換の構造を提供します。

ステータスチェックはガードレールのようなものです。ツールは未完成または失敗したコマンドを誤解を招く出力に変えてはいけません。

イベントログは履歴を追加します。シーケンス、時間、イベントタイプ、詳細を保持するため、オペレーターはリンクの状態が変わった後に何が起こったかを再構築できます。リモートアクセスはローカルモジュールを通じて遠端エンドポイントに到達し、可視パスを完成させます。

これらのワークフローが組み合わさることで、テレメトリは単なる測定可能なだけでなく、実運用が可能になります。
この層での主なリスクは誤った自信です。データを返すように見えるコマンドは、ソフトウェアがワークフローに従いステータスを確認した場合にのみ有用です。証拠には手続きが必要です。
