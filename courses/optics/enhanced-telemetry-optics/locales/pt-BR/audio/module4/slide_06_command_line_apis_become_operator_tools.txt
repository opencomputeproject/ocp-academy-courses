# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
As APIs host SDK e de linha de comando são onde a especificação se torna útil para os operadores. A especificação lista categorias que mapeiam diretamente para os fluxos de trabalho de campo.

O acesso padrão C M I S permite que o software leia o estado local do módulo. O acesso remoto C M I S permite que o software extraia dados padrão do extremo distante. telemetria download expõe parâmetros locais ou remotos do módulo. Comandos de registro de eventos leem eventos recentes, apagam logs e ajustam a histerese. Comandos de firmware gerenciam fluxos de trabalho de atualização locais ou remotos.

A especificação também inclui exibição de tempo de época e de avaliação de link de módulo. Essas categorias importam porque conectam a cadeia de evidências: valores atuais, eventos históricos, correlação temporal e uma pontuação de saúde concisa. Um bom API torna essa corrente utilizável durante a qualificação e durante incidentes.
As categorias API também devem mapear para documentação e treinamento. Os operadores devem saber qual comando recupera a telemetria atual, qual comando recupera eventos recentes, qual comando apaga o histórico e qual comando altera o comportamento.
