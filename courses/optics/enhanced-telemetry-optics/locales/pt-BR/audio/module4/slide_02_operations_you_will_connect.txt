# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Ao final deste módulo, você será capaz de conectar quatro peças operacionais.

Primeiro, você descreverá o gerenciamento de firmware local e remoto sem precisar memorizar todos os identificadores de comando. Segundo, você explicará por que software do host se comunica com o módulo local, mesmo quando o operador quer informações de um parceiro remoto.

Terceiro, você identificará as categorias API que transformam o comportamento do módulo em comandos utilizáveis: acesso ao registrador, download telemetria, logs de eventos, atualização de firmware, tempo de época, histerese e classificação de links.

Por fim, você conectará o histórico de coleta e eventos de telemetria a um mapa de saúde em todo a rede. É aí que o curso passa a ser a prontidão para implantação, e não apenas o conhecimento do protocolo.
Ao revisar os objetivos, pense na transferência de dados. Os dados do módulo tornam-se saída host. host a saída torna-se ação do operador. A ação do operador se encaixa em um processo de implantação repetível. Esse processo repetível é o objetivo.
