# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O gerenciamento de firmware faz parte da confiabilidade porque telemetria só é útil quando a óptica implantada pode ser mantida com segurança. A especificação aponta para o fluxo de gerenciamento de firmware C M I S para operações locais: download de imagens, ativação e monitoramento de status.

Também descreve um protocolo remoto de atualização de firmware definido pelo fornecedor dentro do grupo de comandos de gerenciamento de firmware. Esse caminho remoto utiliza comunicação em banda entre as extremidades local e opostas.

O diagrama de fluxo de origem é denso, o que é normal para uma especificação. A lição que o aprendiz aprende é o padrão do ciclo de vida. Descubra capacidade. Comece a atualização. Transfira a imagem. Complete o download. Execute a imagem. Comprometa como o padrão futuro ou aborte se o processo falhar.
Fluxos de trabalho de firmware também precisam de auditabilidade. Os operadores devem saber qual imagem foi descoberta, o que foi transferido, qual status foi retornado e se a ativação ou commit realmente foi concluído antes de declarar a atualização bem-sucedida.
