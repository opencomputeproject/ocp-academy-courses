# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
A seção software do host descreve uma intenção importante: o Coleta pelo host continuamente o status atual do link para criar uma linha do tempo de desempenho do link que pode ser transmitida para um servidor telemetria para agregação em um mapa de rede de toda a estrutura.

Essa frase conecta todo o curso. Uma única consulta é útil. Uma linha do tempo é melhor. Um mapa de rede é ainda melhor, porque permite que os operadores comparem sintomas entre switches, módulos, faixas, endpoints remotos e tempo.

A linha do tempo deve incluir métricas atuais, registros de registro de eventos, verificações remotas de parceiros e medições do lado do host, como pre-feck B E R e palavras-código não corrigíveis no receptor do servidor do comutador. Quando esses valores se alinham, a solução de problemas passa de alarmes isolados para operações baseadas em evidências.
Uma linha do tempo pode revelar padrões que um snapshot não percebe. Por exemplo, um aumento de temperatura antes dos relinks, ou um eventa extremidade remota antes de um alarme local, pode mudar a investigação de suposições para análise de sequência.
