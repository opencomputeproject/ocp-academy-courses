# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
As métricas deste módulo não são apenas uma longa lista. Eles são uma forma de transformar o estado do link em ação.

Métricas de qualidade ajudam a localizar se o sinal fraco é elétrico, óptico, do lado da linha, do lado do host ou específico da faixa. Métricas de erro e recuperação mostram se a fraqueza está causando carga de correção, relinks ou comportamento não corrigível. Os campos ambientais e de identidade tornam as evidências rastreáveis.

A pontuação link-health então comprime essa evidência cuidadosamente. Ele usa a categoria mais fraca em vez de uma média, porque um único campo ruim ainda pode ser a razão pela qual um link é pouco confiável. Essa ideia nos prepara para a camada do fluxo de trabalho: como o software do host solicita, verifica, recupera e registra os dados.
O teste prático é se a métrica muda uma decisão. Isso aponta para limpeza óptica, substituição de módulo, revisão de firmware, inspeção térmica ou monitoramento contínuo? Acionável telemetria reduz o próximo passo.
