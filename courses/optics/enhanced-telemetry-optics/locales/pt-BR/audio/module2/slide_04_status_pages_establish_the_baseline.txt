# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Antes de falarmos sobre os scores de saúde, o módulo precisa de status de referência. A especificação aponta para páginas comuns de C M I S Bank zero, páginas de configuração e status, páginas de V D M, páginas de comandos C D B, C D B carga útil e páginas personalizadas de fornecedores.

Para este curso, o ponto importante não é o número exato da página para cada área. O ponto importante é que a telemetria aprimorada está sobre uma interface de gerenciamento estruturada. O host pode recuperar informações padrão de identidade e status, então usar as definições aprimoradas telemetria para fazer perguntas mais profundas sobre confiabilidade.

Essa sobreposição mantém o curso prático. Você deve saber onde os mapas detalhados estão, mas seu primeiro modelo mental deve ser: identidade e estado primeiro, depois medições, depois interpretação de saúde.
Páginas de referência também são como o software evita interpretar mal o contexto. Informações de identidade, capacidade e estado devem ser verificadas antes que uma ferramenta assuma que um campa telemetria está disponível, está atual ou é relevante para o módulo em teste.
