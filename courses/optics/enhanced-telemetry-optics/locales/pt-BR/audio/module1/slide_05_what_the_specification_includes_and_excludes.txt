# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O escopo está fazendo um trabalho útil aqui. A especificação se aplica a transceptores compatíveis 400G, 800G e 1.6T, e é destinada a ser independente do módulo P M D, ou implementação dependente de mídia física. Em outras palavras, a interface de telemetria não deve depender de um único detalhe óptico de implementação.

A especificação também se baseia em C M I S, a Especificação de Interface de Gerenciamento Comum de OIF. Ele não substitui C M I S. Ele utiliza funções C M I S e adiciona definições e modificações específicas para que a óptica telemetria possa responder perguntas operacionais de forma mais consistente.

A exclusão também importa. O servidor telemetria está fora do escopo. Isso dá espaço aos operadores para integrar os dados do módulo e host em sua própria pilha de observabilidade sem enfraquecer a interface comum na fronteira do transceptor.
O controle de mira não é uma fraqueza. É isso que torna a contribuição implementável. Ao padronizar a interface enquanto deixa o design de servidores de nível mais alto aberto, o modelo pode se ajustar a diferentes ambientes de operadores sem forçar uma única pilha de observabilidade.
