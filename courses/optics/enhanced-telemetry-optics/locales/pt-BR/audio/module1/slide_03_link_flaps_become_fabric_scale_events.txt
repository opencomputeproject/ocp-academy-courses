# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Uma oscilação do link é fácil de nomear e difícil de diagnosticar. O interruptor diz que o link mudou de estado, mas as evidências podem estar em vários lugares. Pode estar no lado elétrico voltado para o interruptor de um módulo. Pode estar no caminho óptico. Pode estar no lado elétrico voltado para o hospedeiro na extremidade remota.

Essa diferença aumenta em redes de AI porque a contagem de links, o acoplamento de tráfego e a pressão operacional aumentam juntos. Um alarme local não explica automaticamente se o módulo local, módulo remoto, caminho de fibra, receptor host ou um evento de limiar causou o problema.

A especificação responde empurrando um modelo comum telemetria para óptica compatível e software do host. Isso dá aos operadores uma linguagem compartilhada para integridade do link, não apenas uma coleção de comandos de depuração específicos de cada fornecedor.
Isso também muda a forma como as equipes colaboram. Uma equipe de software de switch, fornecedor de óptica, laboratório de qualificação e equipe de operações podem olhar para a mesma falha e ainda assim usar ferramentas diferentes. Comum telemetria lhes dá uma camada de evidência compartilhada.
