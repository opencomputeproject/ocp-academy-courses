# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Uma mudança fundamental é parar de pensar em um link apenas como o caminho da fibra. A figura ponto a ponto divide a conexão em segmentos monitorados. De um lado, o interruptor comunica eletricamente com seu módulo local. No meio, os dois módulos se comunicam opticamente. No outro lado, o módulo remoto comunica eletricamente com o host.

Essa segmentação importa durante o depuro. Um sinal óptico ruim não significa a mesma coisa que um problema de receptor elétrico host. Um alarme local pode estar reportando um sintoma cuja causa está em um segmento remoto.

O modela telemetria dá ao software do host uma forma de pedir evidências ao longo de todo o caminho. Uma vez que cada segmento pode ser medido e relatado de forma consistente, os operadores podem raciocinar sobre onde reside a degradação em vez de trocar as peças por instinto.
Essa visão segmentada também é útil quando os sintomas discordam. Um host pode ver um comportamento, um módulo pode registrar outro, e o parceiro remoto pode apresentar um terceiro. O modelo te dá lugares para comparar, não apenas lugares para culpar.
