# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
A visão geral nos traz seis funções para se lembrar. Primeiro, transceptores compatíveis monitoram links no modo missão, ou seja, o módulo coleta estatísticas enquanto o link está realizando um trabalho útil.

Segundo, o módulo reporta integridade do link por meio de uma métrica comum e acompanha telemetria ao longo do tempo. Terceiro, o módulo suporta comunicação transparente dentro da banda para que as duas extremidades do link possam se identificar e trocar dados.

Quarto, o módulo pode notificar e registrar eventos na memória não volátil. Quinto, suporta atualização de firmware sem acerto em transceptores locais e remotos. Sexto, o software de switch pode coletar o módula telemetria e prepará-lo para streaming em um servidor.

Essas funções são mais fáceis de lembrar como uma cadeia: medir, pontuar, alcançar o extremo distante, preservar a história, atualizar com segurança e alimentar o sistema operacional.
Note que nenhuma dessas funções é isolada. Monitorar sem registrar perde histórico. O registro sem alcance remoto perde o contexto do endpoint. atualização de firmware sem feedback de status aumenta o risco. A confiabilidade vem das funções trabalhando juntas.
