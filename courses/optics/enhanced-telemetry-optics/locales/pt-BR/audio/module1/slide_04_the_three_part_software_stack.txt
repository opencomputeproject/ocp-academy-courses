# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O documento fonte nomeia três componentes em um sistema de software compatível. O primeiro é o próprio transceptor: firmware, métricas telemetria, registro de eventos e o comportamento de comandos necessário para expor esses valores.

O segundo é software do host, normalmente no switch. Esta é a camada que se comunica com o módulo local sobre I ao quadrado C, pede dados de parceiros locais ou remotos e transforma as respostas do módulo em ferramentas que um operador pode usar.

O terceiro é o software de servidor de telemetria. A especificação espera que telemetria seja compilada, resumida e reportada no nível da rede, mas não prescreve como cada operador constrói esse lado do servidor. Esse limite é importante. O curso ensina a interface comum módulo-para-hospedeiro, porque é essa parte que a contribuição padroniza.
Essa visão em camadas também ajuda na responsabilidade. O transceptor possui o que pode medir e preservar. O host assume como pede e apresenta. O servidor telemetria possui uma correlação mais ampla entre a ambiente em larga escala.
