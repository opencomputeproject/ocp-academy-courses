# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
A página 9Fh é onde reside a conversa sobre controle. A especificação aponta para a página de mensagens C M I S C D B e identifica os campos do cabeçalho de comando, campos do cabeçalho de resposta e a área local carga útil.

Para fins de curso, não precisamos ensinar todos os bytes. O conceito duradouro é a separação dos papéis. O host escreve o comando. O módulo informa o status e retorna a resposta. A área carga útil carrega os dados que pertencem àquela solicitação.

Isso importa porque muitas ferramentas de operador dependem, em última análise, da mesma disciplina de nível inferior. Se o software pular a verificação de status ou ler a resposta cedo demais, corre o risco de transformar um modelo de comando estruturado em uma saída de depuração pouco confiável.
Este é um bom lugar para separar detalhes de implementação de detalhes de aprendizado. Engenheiros que implementam a interface precisam dos byte maps. Aprendizes que operam o sistema precisam saber o que os mapas de bytes estão organizando.
