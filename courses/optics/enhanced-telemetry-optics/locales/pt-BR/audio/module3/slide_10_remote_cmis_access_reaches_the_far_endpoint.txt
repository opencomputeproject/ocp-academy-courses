# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O acesso remoto C M I S estende o mesmo modelo até o extremo distante. O host não abre um caminho de gerenciamento direto separado para o módulo remoto. Ele solicita o módulo local compatível, e o módulo local recupera os dados remotos na banda.

Conceitualmente, existem dois modos de acesso úteis. O acesso por bytes é direcionado. É apropriado quando o software precisa de um campo pequeno ou de um alcance estreito. O acesso à página é mais amplo. Ele recupera um snapshot maior orientado a páginas.

Isso é poderoso para operações porque oferece ao switch host uma forma de inspecionar ambas as extremidades do enlace óptico. O operador pode comparar evidências locais e remotas sem acessar fisicamente a extremidade remota primeiro.
O acesso remoto também ajuda quando o acesso físico é lento ou indisponível. Antes de enviar alguém para um rack ou substituir um módulo, o operador pode coletar evidências de extremidade e decidir se a ação é justificada.
