# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
A recuperação de telemetria fica mais fácil de entender quando o padrão C D B fica claro. O host faz um pedido. O módulo local coleta ou recupera os campos relevantes. O host verifica o status do comando. Então ele lê a resposta.

A resposta pode incluir pontuação de vida, identidade do módulo, contadores link-down, tempo de atividade, flags, métricas de qualidade, temperatura, voltagem, energia recebida, comportamento de erro e informações feck. O mapa exato do campo pertence à especificação, mas o modelo operacional pertence à sua cabeça.

Uma forma útil de pensar é a seguinte: o comando coleta um instantâneo coerente para o operador. Em vez de enviar pessoas para buscar campos dispersos, o fluxo de trabalho empacota as evidências necessárias para responder perguntas sobre saúde de links.
Para um aprendiz, o segredo é a repetibilidade. Depois de entender o padrão, você pode reconhecer a mesma estrutura por trás de diferentes comandos de operador, mesmo quando os nomes dos comandos e os campos carga útil mudam.
