# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
C D B dá ao host e ao módulo um padrão comando-resposta. A especificação descreve uma sequência típica em quatro etapas.

Primeiro, o host prepara a mensagem de comando preenchendo os campos de cabeçalho necessários e carga útil. Segundo, ele aciona o comando escrevendo a mensagem no local apropriado. Terceiro, ele consulta os registradores de status C D B para monitorar o progresso. Quarto, quando o comando está completo, ele recupera o cabeçalho de resposta e carga útil.

Esse padrão é a base deste módulo. Seja o host recuperanda telemetria, solicitando registros de registro de eventos ou usando uma área maior de carga útil, a disciplina operacional é a mesma: escrever a solicitação, acioná-la, verificar o status e então ler a resposta.
Os quatro passos também facilitam a resolução de problemas quando o software apresenta problemas inadequados. Você pode perguntar se o comando foi formado corretamente, se foi acionado, se o status foi lido e se a resposta correspondeu ao completamento.
