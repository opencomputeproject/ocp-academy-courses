# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Este módulo transforma telemetria em fluxo de trabalho. C D B dá ao software do host uma sequência comando-resposta repetível: preparar, disparar, sondar e recuperar. As páginas 9Fh e carga útil fornecem a estrutura para essa troca.

A verificação de status é o guardrail. Uma ferramenta não deve transformar um comando inacabado ou falhado em um resultado enganoso.

Os registros de eventos então adicionam o histórico. Eles preservam sequência, tempo, tipo de evento e detalhes para que os operadores possam reconstruir o que aconteceu após a mudança de estado do link. O acesso remoto C M I S completa o caminho de visibilidade ao alcançar a extremidade distante através do módulo local.

Juntos, esses fluxos de trabalho tornam a telemetria operacional em vez de apenas mensurável.
O principal risco nessa camada é a falsa confiança. Um comando que parece devolver dados só é útil se o software seguiu o fluxo de trabalho e verificou o status. A evidência precisa de um processo por trás disso.
