# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Ao final deste módulo, você será capaz de rastrear o fluxo de trabalho de quatro etapas C D B: preparar a mensagem de comando, acionar o comando, consultar os registradores de status e recuperar a resposta.

Você também poderá explicar o propósito das páginas Page 9Fh e estendidas carga útil sem decorar os campos de bytes deles.

Depois, conectaremos o fluxo de trabalho de comandos aos logs de eventos. Os registros de eventos importam porque preservam o tempo, a identidade e o tipo de evento mesmo após o sintoma imediato ter passado.

Por fim, você vai distinguir o acesso remoto por bytes do acesso remoto à página. Ambos são formas de alcançar informações no extremo distante por meio do módulo local compatível.
Os fluxos de trabalho podem parecer de baixo nível, mas não são apenas para engenheiros de firmware. Os operadores sentem o impacto quando uma ferramenta tenta corretamente, reporta falhas claramente ou preserva um registro de evento após a recuperação do link.
