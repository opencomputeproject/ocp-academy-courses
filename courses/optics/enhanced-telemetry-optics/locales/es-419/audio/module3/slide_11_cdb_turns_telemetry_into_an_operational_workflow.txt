# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Este módulo convierte la telemetría en flujo de trabajo. C D B da al software del host una secuencia comando-respuesta repetible: preparar, activar, sondear y recuperar. Las páginas 9Fh y carga útil proporcionan la estructura para ese intercambio.

La comprobación de estado es la barrera de seguridad. Una herramienta no debería convertir un comando incompleto o fallido en una salida engañosa.

Los registros de eventos luego añaden historial. Conservan la secuencia, el tiempo, el tipo de evento y el detalle para que los operadores puedan reconstruir lo que ocurrió después de que el enlace cambiara de estado. El acceso remoto C M I S completa la ruta de visibilidad alcanzando el extremo lejano a través del módulo local.

Juntos, estos flujos de trabajo hacen que la telemetría sea operativo en lugar de solo medible.
El principal riesgo en esta capa es la falsa confianza. Un comando que parece devolver datos solo es útil si el software siguió el flujo de trabajo y comprobó el estado. La evidencia necesita un proceso detrás.
