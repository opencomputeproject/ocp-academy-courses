# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I al cuadrado C; VDM -> V D M; SNR -> S N R; FEC -> F E C; BER -> B E R; DSP -> D S P; API -> A P I
El acceso remoto C M I S permite leer y escribir. El host envía la solicitud al módulo local conforme, que alcanza al extremo remoto seleccionado mediante la interfaz en banda.

El acceso por bytes utiliza el comando ocho mil veinte hexadecimal. Selecciona un puerto remoto, banco, página, dirección, operación y longitud. Es útil para un intervalo reducido de registros transferido mediante la carga útil local.

El acceso por páginas utiliza el comando ocho mil veintiuno hexadecimal y la carga útil extendida. Es útil cuando el software necesita leer o escribir una página remota completa en vez de varios intervalos pequeños.

Para el diagnóstico, una lectura recupera evidencia. Una escritura cambia el estado remoto, por lo que la herramienta debe dejar claros la operación y el destino, y seguir los controles de mantenimiento del despliegue.

En ambos modos, compruebe el estado de finalización y de falla del comando antes de confiar en el resultado. Conserve en la salida el extremo seleccionado y el contexto de banco y página.

Esto ofrece visibilidad del extremo remoto mediante una sola interfaz local de gestión. También exige seleccionar cuidadosamente el destino, sobre todo en configuraciones breakout, donde una solicitud válida podría apuntar al extremo equivocado.
