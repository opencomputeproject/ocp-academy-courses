# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
El acceso remoto C M I S extiende el mismo modelo hasta el extremo lejano. El host no abre una ruta de gestión directa separada hacia el módulo remoto. Solicita el módulo local compatible, y el módulo local recupera los datos remotos en la banda.

Conceptualmente, hay dos modos de acceso útiles. El acceso a bytes está dirigido. Es adecuado cuando el software necesita un campo pequeño o un rango estrecho. El acceso a las páginas es más amplio. Recupera una instantánea orientada a páginas más grande.

Esto es potente para operaciones porque proporciona al switch host una forma de inspeccionar ambos extremos del enlace óptico. El operador puede comparar evidencia local y remota sin acceder físicamente primero a la extremo remoto.
El acceso remoto también ayuda cuando el acceso físico es lento o no está disponible. Antes de enviar a alguien a un rack o reemplazar un módulo, el operador puede recopilar pruebas de fondo y decidir si la acción está justificada.
