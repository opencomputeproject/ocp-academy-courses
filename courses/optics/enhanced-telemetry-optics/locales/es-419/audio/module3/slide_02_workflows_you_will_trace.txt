# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Al final de este módulo, podrás rastrear el flujo de trabajo de cuatro pasos C D B: preparar el mensaje de comando, activar el comando, consultar los registros de estado y recuperar la respuesta.

También podrás explicar el propósito de Page 9Fh y las páginas extendidas carga útil sin memorizar sus campos de bytes.

Luego conectaremos el flujo de trabajo de comandos con los registros de eventos. Los registros de eventos importan porque preservan el tiempo, la identidad y el tipo de evento incluso después de que el síntoma inmediato haya pasado.

Por último, distinguirás el acceso remoto por bytes del acceso remoto a páginas. Ambos son formas de acceder a la información en el extremo lejano a través del módulo local compatible.
Los flujos de trabajo pueden parecer de bajo nivel, pero no son solo para ingenieros de firmware. Los operadores sienten el impacto cuando una herramienta intenta correctamente, informa claramente de fallos o conserva un registro de evento después de que el enlace se recupera.
