# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I al cuadrado C; VDM -> V D M; SNR -> S N R; FEC -> F E C; BER -> B E R; DSP -> D S P; API -> A P I
La recopilación continua convierte mediciones aisladas en una línea temporal del rendimiento del enlace. El host puede transmitirla a un servidor de telemetría, donde el operador construye una vista de toda la red.

La sincronización temporal forma parte de ese recorrido de la evidencia. Obtener hora del módulo y Establecer hora del módulo utilizan los comandos cinco hexadecimal y seis hexadecimal. Emplean una representación de sesenta y cuatro bits en nanosegundos relativa a la época POSIX: el inicio de mil novecientos setenta en tiempo universal coordinado.

Las definiciones de telemetría avanzada amplían esos comandos para operaciones remotas. Un host puede consultar la hora de un extremo remoto seleccionado. El comando de ajuste puede dirigirse al módulo local o a los puertos locales y remotos, según su campo de destino.

Las unidades de la marca temporal no determinan la precisión del reloj. El software debe establecer y verificar la referencia temporal antes de comparar eventos entre módulos y hosts.

La línea temporal también incluye las mediciones del propio receptor del switch: B E R previa a F E C y palabras de código no corregibles. Los datos del módulo no cubren por sí solos todos los segmentos receptores.

Al reunir identidad del extremo, hora válida, métricas actuales y eventos persistentes, el operador puede distinguir entre un aumento de temperatura previo a los restablecimientos y una falla remota seguida de una alarma local.
