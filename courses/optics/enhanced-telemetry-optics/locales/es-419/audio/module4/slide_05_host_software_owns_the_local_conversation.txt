# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
El límite host es explícito en la especificación. Toda la comunicación del transceptor compatible con el host local se realiza sobre I cuadrado C. Los comandos emitidos al módulo local pueden solicitar telemetría al transceptor local o a uno de los socios de enlace remoto.

Cuando se solicitan datos remotos, el transceptor local es responsable de recuperarlos y presentarlos al host local. El host local no se comunica directamente con los módulos asociados remotos.

Ese detalle afecta a la arquitectura, la depuración y la revisión de seguridad. software del host puede mantenerse consistente. El módulo se encarga de la recuperación remota dentro de la banda. Los operadores obtienen visibilidad a largo plazo sin inventar un camino de gestión separado para cada punto óptico remoto.
Este límite también simplifica las discusiones sobre el control de acceso. El host puede autorizar y registrar su interacción local, mientras que el módulo compatible gestiona la recuperación remota a través del enlace. Eso es más limpio que muchas rutas de depuración remotas ad hoc.
