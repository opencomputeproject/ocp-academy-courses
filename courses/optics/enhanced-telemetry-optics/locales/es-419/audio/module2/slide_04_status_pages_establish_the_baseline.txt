Antes de hablar de puntuaciones de salud, el módulo necesita un estado base. La especificación apunta a páginas comunes de C M I S de banco, páginas de configuración y estado, páginas de V D M, páginas de comandos C D B, C D B carga útil y páginas de proveedores personalizados.

Para este curso, el punto importante no es el número exacto de página para cada campo. Lo importante es que la telemetría mejorado se sitúa sobre una interfaz de gestión estructurada. El host puede recuperar información estándar de identidad y estado, y luego usar las definiciones mejoradas telemetría para plantear preguntas más profundas sobre fiabilidad.

Esa superposición mantiene el curso práctico. Deberías saber dónde están los mapas detallados, pero tu primer modelo mental debería ser: primero identidad y estado, luego mediciones, y después interpretación de la salud.
Las páginas de referencia también son la forma en que el software evita interpretar mal el contexto. La información de identidad, capacidad y estado debe comprobarse antes de que una herramienta asuma que un campo la telemetría está disponible, está actual o es relevante para el módulo en prueba.
