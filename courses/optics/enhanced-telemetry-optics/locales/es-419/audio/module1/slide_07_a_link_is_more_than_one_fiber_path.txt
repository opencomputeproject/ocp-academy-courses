# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Un cambio clave es dejar de pensar en un enlace solo como el camino de la fibra. La figura punto a punto divide la conexión en segmentos monitorizados. Por un lado, el interruptor se comunica eléctricamente con su módulo local. En el centro, los dos módulos se comunican ópticamente. En el lado opuesto, el módulo remoto se comunica eléctricamente con el host.

Esa segmentación importa durante la depuración. Una señal óptica deficiente no significa lo mismo que un problema con un receptor eléctrico host. Una alarma local puede estar informando de un síntoma cuya causa es en un segmento remoto.

El modelo de telemetría le da al software del host una forma de pedir pruebas a lo largo de todo el camino. Una vez que cada segmento puede medirse y reportarse de forma consistente, los operadores pueden razonar sobre dónde reside la degradación en lugar de intercambiar piezas por instinto.
Esta vista de segmentos también es útil cuando los síntomas no coinciden. Un host puede ver un comportamiento, un módulo puede registrar otro, y el compañero remoto puede mostrar un tercero. El modelo te da lugares para comparar, no solo a los que culpar.
