El primer módulo nos ofrece el modelo mental para el resto del curso. La telemetría mejorado intenta cerrar una brecha de visibilidad entre una alarma local y la evidencia remota o específica de segmento que la explica.

El trabajo estandarizado se sitúa en la interfaz transceptor y host. El servidor telemetría puede variar según el operador, pero el módulo necesita un comportamiento común para que el software de conmutación pueda recopilar datos útiles.

Dos detalles seguirán apareciendo. Primero, la óptica conforme recoge telemetría local y remoto. En segundo lugar, un enlace puede contener múltiples segmentos monitorizados o múltiples socios remotos. El siguiente módulo convierte ese modelo en métricas específicas, indicadores y puntuación de estado del enlace que los operadores pueden utilizar.
Para reseña, vincula todas las funciones posteriores a este modelo compartido. Si una métrica, evento, comando o API no ayuda a localizar o explicar una condición de enlace, probablemente sea un detalle de apoyo y no la lección principal.
