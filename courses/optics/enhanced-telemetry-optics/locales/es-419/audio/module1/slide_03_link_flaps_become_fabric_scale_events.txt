# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Un oscilación del enlace es fácil de nombrar y difícil de diagnosticar. El interruptor te indica que el enlace cambió de estado, pero la evidencia puede estar en varios lugares. Puede estar en el lado eléctrico orientado hacia el interruptor de un módulo. Puede que esté en el trayecto óptico. Puede estar en el lado eléctrico orientado al huésped en el extremo remoto.

Esa brecha se hace más grande en redes de AI porque el número de enlaces, el acoplamiento de tráfico y la presión operativa aumentan juntos. Una alarma local no explica automáticamente si el módulo local, el módulo remoto, el camino de fibra, el receptor host o un evento umbral causaron el problema.

La especificación responde introduciendo un modelo común telemetría en óptica compatible y software del host. Eso da a los operadores un lenguaje compartido para estado del enlace, no solo una colección de comandos de depuración específicos de cada fabricante.
Esto también cambia la forma en que los equipos colaboran. Un equipo de software de interruptores, un proveedor de óptica, un laboratorio de cualificación y un equipo de operaciones pueden revisar el mismo fallo y aun así usar herramientas diferentes. Común telemetría les proporciona una capa de evidencia compartida.
