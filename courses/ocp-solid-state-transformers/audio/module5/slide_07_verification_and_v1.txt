Turn the draft into a verification program. Start with representative steady loads, ramps, steps, faults, and ride-through events. Validate the actual grounding method, insulation monitoring, and selective protection. Test ESS response and recharge, not only discharge. Confirm communications, alarms, time synchronization, state transitions, auxiliary-power behavior, and fail-safe control. Preserve a stable black-box interface so multiple suppliers can demonstrate comparable outcomes. Then track the gaps that separate v0.3 from a deployment-ready v1.0: simulation, laboratory evidence, pilot operation, standards alignment, and supplier feedback. The semi-private SST workstream can mature those details while the public Power Distribution Sub-Project provides the broader community connection.

Verification should include negative tests as well as nominal performance. Remove communications and confirm local safety. Fail an auxiliary source and verify the intended control availability. Create a first ground fault and confirm detection. Apply downstream faults at different locations and verify selective clearing. Start with reduced ESS state of charge and confirm the ride-through policy. Restore the grid and observe recharge under concurrent IT load. Exercise warning and fault transitions, time stamps, event logs, and manual recovery. These scenarios can resolve ambiguous draft language and define interoperable acceptance criteria for version one point zero.
