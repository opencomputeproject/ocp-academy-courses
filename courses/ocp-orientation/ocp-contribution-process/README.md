# OCP Contribution Process

This standalone Scrolling course follows an OCP contribution from initial submission through review, approval, publication, and the tools used throughout the process.

## Lessons

1. Introduction
2. Platform and Process Overview
3. Initiation and Submission
4. Review and Document Preparation
5. Approval and Publication
6. Knowledge Check
7. Summary

## Build

From the repository root:

```bash
./scripts/build-course.sh ocp-orientation/ocp-contribution-process
```

The source of truth is `course.json`. Course-owned learner media and video are retained under `resources/`. Generated SCORM files are not checked in.
