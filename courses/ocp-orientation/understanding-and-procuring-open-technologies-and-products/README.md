# Understanding and Procuring Open Technologies and Products

This standalone Scrolling course explains how procurement teams can evaluate open-technology ecosystems, their benefits, commercial models, and the capabilities needed to adopt them successfully.

## Lessons

1. Introduction
2. Understanding Open Technologies
3. Benefits of Open Technologies
4. Qualifying an Open Technology Ecosystem
5. Open-Source Commercial Models
6. Mastering the Open Technology Game
7. Summary

## Build

From the repository root:

```bash
./scripts/build-course.sh ocp-orientation/understanding-and-procuring-open-technologies-and-products
```

The source of truth is `course.json`. Course-owned learner media, captions, and documents are retained under `resources/`. Generated SCORM files are not checked in.
