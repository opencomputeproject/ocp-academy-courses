**タイトル**\
OCP Solution Providerプログラム入門

**短い説明**\
製品、施設、サービスに合うOCPプログラムを見つけ、Marketplaceへの掲載までの流れを学びます。

**詳しい説明**

OCP Solution Providerプログラムは、製品、施設、サービスを、それらを活用する人につなぎます。それぞれの認定の意味、裏付けとなる根拠、参加から分かりやすく役立つMarketplace掲載までの流れを学びます。

**合計所要時間：7分**

**モジュール1：OCP Solution Providerプログラム入門 — 7分**\
Marketplaceの製品、チップレット、統合ソリューション、サービス、施設、Experience Centerを見ていきます。OCP Accepted製品認定、S.A.F.E.のファームウェアセキュリティ審査、OCP Ready施設認定の違いを学びます。根拠資料、審査、契約の流れをたどり、Experience Centerの役割、会員資格、料金、正式なマーク、掲載情報の更新について理解します。
