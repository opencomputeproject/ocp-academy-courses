**제목**\
OCP Solution Provider 프로그램 소개

**간단한 설명**\
제품, 시설, 서비스에 맞는 OCP 프로그램을 찾고 Marketplace 목록 게시까지의 경로를 이해합니다.

**상세 설명**

OCP Solution Provider 프로그램은 제품, 시설, 서비스를 사용할 사람과 연결합니다. 각 인정의 의미와 뒷받침하는 근거를 이해하고, 참여에서 명확하고 유용한 Marketplace 목록까지 이어지는 과정을 알아봅니다.

**총 학습 시간: 7분**

**모듈 1: OCP Solution Provider 프로그램 소개 — 7분**\
Marketplace의 제품, 칩렛, 통합 솔루션, 서비스, 시설, Experience Center를 살펴봅니다. OCP Accepted 제품 인정, S.A.F.E. 펌웨어 보안 검토, OCP Ready 시설 인정을 구분합니다. 근거, 검토, 계약 단계를 따라가며 Experience Center의 역할, 회원 자격, 비용, 공식 마크, 목록 정보 관리 방법을 배웁니다.
