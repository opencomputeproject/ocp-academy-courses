A cluster contains several kinds of traffic. Scale-up communication stays within a high-bandwidth compute domain. Scale-out communication connects those domains. The January architecture also separates a CPU-facing scale-out network, called S O C, from storage. An in-band network supports host management and services. A separate out-of-band network reaches hardware management controllers and supports recovery when the host operating system is unavailable. The April references use S O C and front-end terminology for the CPU-facing service path and offer configurations that converge it with storage. Read the function and the chosen configuration together. Six named functions do not always require six separately built physical fabrics. Equally, combining traffic does not remove its capacity, policy, or failure requirements. Connections between clusters or across distance introduce another boundary; they are not a complete design supplied by these single-cluster examples.
