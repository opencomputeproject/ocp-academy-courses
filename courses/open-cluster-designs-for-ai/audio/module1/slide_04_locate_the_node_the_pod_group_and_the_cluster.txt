# pronunciation: AI = quoted A I; xPU = ex pee you; OPG = O P G; XOC = X O C; SONiC = sonic; RoCE = rocky; CRD = C R D; RDMA = R D M A

Read the hierarchy from the compute domain outward. An ex pee you is a generic accelerator. In the January example, an ex pee you node is a server containing eight accelerators and the resources they need. Its high-bandwidth scale-up connections are inside that server. A larger scale-up pod can have a different physical shape, including a rack-scale arrangement. An Open Pod Group, or O P G M, combines compute domains with networking, storage, management, and supporting infrastructure. M denotes the accelerator count in that group. An X O C N is a complete scale-out cluster containing N accelerators. It combines one or more pod groups with the shared resources needed at cluster level. Follow those boundaries in the animation. A node is not a pod group, and a pod group is not automatically a complete cluster. These are architectural domains. Their physical packaging can change.
