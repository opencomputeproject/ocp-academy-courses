# pronunciation: OPG-128 = O P G one hundred twenty-eight; XOC-1k = X O C one K; OSFP = O S F P; Clos = Kloh (rhymes with go or slow; silent s)

Read this original Kloh plan from the shared spine layer down to the pod groups. Eight scale-out spine switches sit across the top of the network. Along the bottom are eight O P G one hundred twenty-eight building blocks. Each group has two fifty-one-terabit-class leaves, giving sixteen leaves across the cluster. The blue lines represent four-hundred-gigabit optical connections between the leaf and spine layers. The lower callout expands one leaf's connections toward the accelerator nodes. The port legend above the network explains how the document identifies a switch port and an optical-module port separately. An eight-hundred-gigabit O S F P module can expose two four-hundred-gigabit connections, so those identities still matter. This is a complete January example with specified hardware and port allocations. It does not establish the switch count for every possible Kloh network.
