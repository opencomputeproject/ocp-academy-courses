Compare two services. The first serves a model entirely within one server for each request. Requests are independent and enter through a gateway. The second splits a model across hosts and exchanges intermediate results on the request path. Which inference profile would you start from for each? Minimal Inference can fit the first service, provided its other assumptions hold. Distributed Inference supplies the back-end needed by the second. Now add a second question: what must be measured before accepting either choice? For the first, include gateway behavior and request latency under load. For the second, include the cross-host path and its congestion and failure behavior as well. These are starting designs to qualify, not performance guarantees attached to a profile name.
