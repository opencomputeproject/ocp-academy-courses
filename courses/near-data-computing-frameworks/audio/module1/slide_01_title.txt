# pronunciation: OCP -> O C P
Module one. Choosing where computation runs. Near data computing starts with a placement question: which work should happen beside the data, and which work belongs on the host? We'll build a common vocabulary, compare two architecture options, and practice making a placement hypothesis. This course follows a working O C P framework draft. Some ideas are established, some have been demonstrated, and others are questions for the Data Centric Computing community to resolve.
