# pronunciation: SROI -> "S R O eye"; XPU -> "X P U"; radix -> "raid-icks"; retries -> "ree-tries"
The first module gives us the boundary conditions for the rest of the course.

Scale-up is part of the compute path. It carries tightly coupled, memory-semantic work, so bandwidth shortfalls, ree-tries, and latency can strand X P U capacity across the Pod.

Raid-icks turns total switch I O into a tradeoff between link width and connected accelerator count. As Pods expand across racks, copper reach and package escape become structural limits.

S R O eye defines the optical region that begins when those limits no longer match the system geometry. Its upper boundary is thirty meters. Within that reach, endpoint density, energy, cost, latency, and reliability matter more than the long-channel impairments that define D R and F R optics.

That common physical layer can serve multiple protocol families. The next question is where, within a real system, copper stops and optics begins.
