# pronunciation: OCP -> "O C P"; L.O.C.K. -> "lock"; MEK -> "meck"; DPK -> "D P K"; MPK -> "M P K"; HEK -> "heck"; SEK -> "seck"; EPK -> "E P K"; MDK -> "M D K"
Module two. O C P lock key hierarchy and cryptographic erase.

The trust boundary from module one becomes useful only when every Media Encryption Key depends on the right protection layers. A Data Protection Key represents the owner. Optional Multi-party Protection Keys add other authorities. Hard and Soft Epoch Keys make erase a change in cryptographic state. An M D K constrains the final hardware path.

This module follows those keys through generation, storage, enablement, rotation, and zeroization. By the end, you'll be able to reconstruct the protection chain and explain why different erase operations serve different operational boundaries.
