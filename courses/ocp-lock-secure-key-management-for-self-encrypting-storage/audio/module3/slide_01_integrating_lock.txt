Module three. Integrating O C P lock: interfaces and compliance.

The key hierarchy protects data only when every request, reset, and error follows the intended path. Drive firmware talks to the Key Management Block through a mailbox. The K M B talks to the encryption engine through special function registers. A defined command sequence builds the media-key secret before a key can be generated, loaded, or derived.

This module maps those interfaces, then closes with the thirteen mandatory controls in version one point one. By the end, you'll be able to review an integration flow for both functional order and security boundaries.
