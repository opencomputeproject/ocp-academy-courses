# pronunciation: OCP -> "O C P"; L.O.C.K. -> "lock"; MEK -> "meck"; Caliptra -> "Caliptra"; KMB -> "K M B"; SED -> "S E D"; 1.1 -> "one point one"
Module one. O C P lock stands for Layered Open-source Cryptographic Key Management. This module focuses on trust boundaries and security goals for data-at-rest keys.

Self-encrypting drives already encrypt user data, but encryption alone doesn't prove that the keys were protected or erased correctly. O C P lock version one point one moves Media Encryption Keys into a protected Caliptra Key Management Block. Drive firmware can request key-lifecycle operations, but it can't read the raw keys.

This module explains the operating problem, the adversary the design assumes, and the trust boundary that makes the design useful. Narration starts automatically. Use the arrow controls, or press Space, when you're ready to advance.
