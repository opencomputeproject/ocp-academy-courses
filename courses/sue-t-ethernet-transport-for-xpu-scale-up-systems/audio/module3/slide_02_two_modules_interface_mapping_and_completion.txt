The remaining two modules connect interface mapping to completion. This module explains how the accelerator identifies a destination, carries application-specific information, and represents requests on the wire. You'll also see what ordering is and isn't guaranteed by the A X I identifier.

The next module examines completion. We'll compare four alternative points at which a write may be reported complete, then apply those choices to a concrete write-and-read case.

Keep the questions connected. A correctly encoded packet doesn't settle the memory-ordering contract. An operation response doesn't always establish observer-visible memory placement. Integration requires you to define both the representation and the event that the response confirms. The specification provides the constraints and examples; the implementation makes several of the choices.
