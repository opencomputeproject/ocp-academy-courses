# pronunciation: SUE-T -> "S U E T"; XPU -> "X P U"; 1.0.0 -> "one point zero point zero"
Scale-Up Ethernet Transport, or S U E T, connects the memory-transaction interface of an accelerator to an Ethernet scale-up network. An X P U is the generic accelerator in this specification.

You'll follow a transaction through that endpoint and learn what its acknowledgement actually means. That distinction matters when a system reports success before data is visible in memory. This course uses the S U E T Base Specification, version one point zero point zero. Let's begin with the endpoint's responsibilities.
