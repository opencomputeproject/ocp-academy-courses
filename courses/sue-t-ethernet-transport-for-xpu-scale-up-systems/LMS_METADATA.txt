TITLE
SUE-T: Ethernet Transport for XPU Scale-Up Systems

SHORT DESCRIPTION
Trace transactions, explain reliable delivery, and define accelerator completion contracts.

LONG DESCRIPTION
Learn how SUE-T v1.0.0 carries accelerator memory transactions over an Ethernet scale-up fabric. Trace command mapping and acknowledgements, predict packet packing and recovery, map XPU and AXI interfaces, and compare completion points, memory visibility, and error handling. This intermediate technical course includes narrated slides, six synchronized teaching videos, worked examples, and knowledge checks. Allow about 75 minutes, including practice and review.

Module 1: From XPU Transactions to Ethernet Transport — about 18 minutes. Endpoint scope, transaction flow, ACK modes, and visibility.
Module 2: Efficient Packets on a Lossless Fabric — about 25 minutes. Queue service, packing limits, PDC state, and lossless reliability.
Module 3: Map the XPU Interface to the Transport — about 16 minutes. Command/network roles, identity, ordering, and encoding.
Module 4: Define Completion and Evaluate the Design — about 16 minutes. Visibility, errors, cleanup, and a worked AXI write.

AUDIENCE
Intermediate technical

ESTIMATED LEARNING TIME
75 minutes

FORMAT
One SCORM 1.2 package with Course Home and four tracked modules; 47 narrated slides, six synchronized videos, eight knowledge-check questions.
