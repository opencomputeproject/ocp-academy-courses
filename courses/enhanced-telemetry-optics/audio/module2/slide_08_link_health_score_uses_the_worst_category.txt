# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
A health score should preserve the measurement that needs action. Averaging healthy fields with one failing field can hide the problem.

The specification first evaluates each supported category against its thresholds. The defined category scores are eighty, sixty, and forty. It then takes the minimum as the rating for the selected host or media side.

Host-side categories include electrical signal quality, pre-feck B E R, module flags, and the defined counters when enabled. Media-side scoring also includes optical-specific evidence such as M P I, optical-power flags, and laser-bias flags. The two sides do not use an identical category list.

The animation shows selected media-side categories. When the B E R category falls to forty, the minimum follows it. An average still looks healthier, which is exactly the information loss the specification avoids.

The telemetry reply also carries a lowest-rating-category bitmap. Multiple bits can be set when categories tie for the minimum. Read that bitmap and the underlying values rather than choosing only one presumed cause.

Finally, interpret the result with the effective counter masks and threshold settings. A score has meaning only with its configuration and endpoint context.
