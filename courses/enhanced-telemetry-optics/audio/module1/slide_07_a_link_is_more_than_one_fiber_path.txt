# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
A link is more than the fiber between two modules. There are three interface regions: the switch-to-module electrical connection, the optical connection between modules, and the module-to-server electrical connection.

Traffic travels in both directions, so the specification describes six directional link segments. Each receiver sees a particular incoming signal. A poor result at one receiver does not automatically identify the transmitter, fiber, or electrical interface as the cause.

This distinction explains why module telemetry and host receiver measurements belong together. The switch also records its own pre-feck B E R and uncorrectable codewords. Remote telemetry helps expose the far-side module even when the operator cannot directly access the server.

The animation groups the six directions into the three interface regions. Use that view to organize the investigation, then compare the measurements at the relevant receiving endpoints.

If symptoms disagree, preserve that disagreement as evidence. A local alarm, a remote event, and a host-side error pattern may describe different parts of the same failure. Segment identity makes those observations useful.
