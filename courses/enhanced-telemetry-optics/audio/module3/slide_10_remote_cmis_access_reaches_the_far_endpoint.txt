# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
Remote C M I S access supports both reading and writing. The host sends the request to the local compliant module, which reaches the selected remote partner through the in-band interface.

Byte access uses command eight thousand twenty hex. It selects a remote port, bank, page, address, operation, and length. It is useful for a narrow register range carried through the local payload.

Page access uses command eight thousand twenty-one hex and the extended payload. It is useful when software needs to read or write a complete remote page rather than several small ranges.

For diagnosis, a read retrieves evidence. A write changes remote state, so the tool should make the operation and destination clear and follow the deployment's maintenance controls.

In either mode, check command completion and failure status before trusting the result. Preserve the selected partner and bank/page context in the output.

This gives operators far-end visibility through one local management interface. It also makes careful targeting essential, especially in breakout configurations where an otherwise valid request can still be aimed at the wrong partner.
