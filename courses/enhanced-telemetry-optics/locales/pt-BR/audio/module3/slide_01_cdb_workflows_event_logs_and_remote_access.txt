# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O módulo três vai do que é medido para como o host o consegue. A especificação usa C D B, ou Bloco de Dados de Comando, para troca comando-resposta entre host e módulo.

Vamos manter o nível conceitual. Você precisa entender o fluxo de trabalho de preparar, disparar, consultar e recuperar. Você também precisa entender por que a verificação de status, registros de eventos, acesso remoto C M I S e carga útil são relevantes para operações confiáveis.
Se o módulo dois era o vocabulário, este módulo é a gramática. C D B define como requisições e respostas são estruturadas para que software do host possa pedir dados repetidamente e interpretar o resultado com confiança.
