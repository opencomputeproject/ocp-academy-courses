# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Um fluxo comum de confiabilidade tem três camadas. O transceptor implementa firmware, medições, histórico de eventos e o comportamento dos comandos necessário para expor evidências locais e remotas.

O software do host, normalmente em um switch, descobre o que o módulo suporta, solicita dados, verifica os resultados dos comandos e prepara a saída para as ferramentas operacionais. O host continua sendo o ponto de controle local mesmo quando a informação solicitada vem de um parceiro de link remoto.

Acima disso, o software do servidor de telemetria pode compilar, resumir e relatar a integridade da rede. Sua implementação depende do operador. A especificação define o comportamento do módulo e a interface comum com o host, em vez de exigir um único projeto de servidor de monitoramento.

Essa divisão importa durante a integração. Um fornecedor pode implementar a interface do módulo, uma equipe de switches pode implementar a coleta e o operador pode escolher ferramentas de agregação adequadas à implantação. A fronteira compartilhada permite que essas escolhas funcionem em conjunto.

Durante um incidente, siga as mesmas camadas. Pergunte se a evidência existe no módulo, se o host a recuperou corretamente e se o sistema de monitoramento preservou o contexto.
