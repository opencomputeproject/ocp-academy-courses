# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Ao final deste módulo, você relacionará o comportamento do protocolo a operações repetíveis.

Primeiro, diferenciará o fluxo padrão de firmware C M I S local da família remota de comandos 8030h. Explicará por que baixar, executar e confirmar uma imagem são etapas separadas.

Segundo, descreverá a fronteira do host. O host se comunica com seu módulo local por I ao quadrado C, enquanto esse módulo recupera dados de parceiros remotos em banda.

Terceiro, identificará as categorias de ferramentas necessárias aos operadores: acesso a registradores, telemetria, histórico de eventos, manutenção de firmware, horário do módulo, histerese e classificação de integridade.

Por fim, relacionará os carimbos de tempo do módulo e as medições dos receptores do host à mesma linha do tempo de evidências. Verificará capacidades, identidade do parceiro, configuração da pontuação, padrões de desligamento e resultados do firmware antes de confiar na implantação durante um incidente.

O objetivo é uma passagem confiável das medições do módulo para a saída do host, da saída do host para as decisões dos operadores e dessas decisões para ações documentadas.
