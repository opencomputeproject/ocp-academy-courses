# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
A coleta contínua transforma medições isoladas em uma linha do tempo de desempenho do link. O host pode transmiti-la a um servidor de telemetria, onde o operador constrói uma visão de toda a rede.

A sincronização de horário faz parte desse caminho de evidências. Get Module Time e Set Module Time usam os comandos 0005h e 0006h. Eles usam uma representação de sessenta e quatro bits em nanossegundos em relação à época POSIX, o início de mil novecentos e setenta no horário universal coordenado.

As definições de telemetria avançada estendem esses comandos para operações remotas. Um host pode consultar o horário de um parceiro remoto selecionado. O comando de definição pode endereçar o módulo local ou as portas locais e remotas, conforme definido pelo campo de destino.

As unidades do carimbo de tempo não determinam a precisão do relógio. O software ainda precisa estabelecer e verificar a referência de tempo antes de comparar eventos entre módulos e hosts.

A linha do tempo também inclui as medições dos receptores do próprio switch: B E R pré-FEC e palavras-código não corrigíveis. Os dados do módulo, sozinhos, não cobrem todos os segmentos receptores.

Com identidade dos endpoints, horário válido, métricas atuais e registros persistentes de eventos em conjunto, o operador pode distinguir um aumento de temperatura antes de relinks de uma falha remota seguida por um alarme local.
