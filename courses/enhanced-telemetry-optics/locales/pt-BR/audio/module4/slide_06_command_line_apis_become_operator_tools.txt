# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O SDK do host transforma a interface comum do módulo em fluxos de trabalho dos operadores. A especificação descreve uma implementação SONiC e um conjunto de categorias de APIs de linha de comando.

O acesso C M I S local e remoto expõe o estado dos registradores. O download de telemetria exibe medições para um endpoint, lado e porta selecionados. As ferramentas de eventos recuperam o histórico recente em formato legível, controlam a histerese e limpam o histórico apenas quando essa é a intenção.

As ferramentas de firmware executam a manutenção local ou remota com a família apropriada de comandos e resultados verificados do ciclo de vida. Os controles de horário do módulo fornecem a referência necessária para comparar registros, enquanto a exibição da classificação do link oferece uma entrada concisa para as evidências subjacentes.

As ferramentas de qualificação e diagnóstico também precisam de descoberta de capacidades, controle de máscaras de contadores, controle de limiares e verificação do estado do desligamento. Os comandos de nível inferior definem essas operações mesmo quando uma interface de usuário específica as agrupa de outra forma.

Mantenha claramente separadas as leituras e as mudanças de configuração. Recuperar o histórico, limpá-lo e alterar a reação do módulo são ações diferentes.

Uma ferramenta útil informa o destino, a capacidade suportada, a configuração efetiva e o resultado do comando junto com o valor. Esse contexto torna a saída confiável durante um incidente real.
