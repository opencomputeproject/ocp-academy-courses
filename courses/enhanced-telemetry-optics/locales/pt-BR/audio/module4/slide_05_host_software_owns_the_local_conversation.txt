# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
O limite host é explícito na especificação. Toda comunicação compatível do transceptor com o host local é realizada sobre I ao quadrado C. Comandos emitidos para o módulo local podem solicitar telemetria do transceptor local ou de um dos parceiros de enlace remoto.

Quando dados remotos são solicitados, o transceptor local é responsável por recuperar esses dados e apresentá-los ao host local. O host local não se comunica diretamente com os módulos parceiros remotos.

Esse detalhe afeta arquitetura, depuração e revisão de segurança. software do host pode permanecer consistente. O módulo cuida da recuperação remota dentro da banda. Os operadores obtêm visibilidade de extremidade distante sem precisar inventar um caminho de gerenciamento separado para cada endpoint óptico remoto.
Esse limite também simplifica discussões sobre controle de acesso. O host pode autorizar e registrar sua interação local, enquanto o módulo compatível cuida da recuperação remota pelo link. Isso é mais limpo do que muitos caminhos de depuração remota ad hoc.
