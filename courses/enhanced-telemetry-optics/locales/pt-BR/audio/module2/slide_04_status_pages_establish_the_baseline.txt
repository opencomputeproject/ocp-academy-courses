# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
A descoberta de capacidades vem antes da interpretação da telemetria. Um campo não suportado ou um parceiro remoto inacessível não deve aparecer como um zero saudável.

A especificação versão um ponto zero ponto zero define o comportamento anunciado como Telemetry Version dois. Esse identificador de protocolo é informado na página 01h, byte 191. Ele não é o número da versão do documento.

O software também verifica o suporte ao recurso em banda e se a lane de comunicação está estabelecida. São perguntas diferentes. Alguns módulos oferecem detecção automática de lane em banda, permitindo um link básico com um parceiro sem telemetria avançada. Portanto, o simples estabelecimento do link não comprova a visibilidade remota.

O comando de anúncio de capacidades, 8000h, retorna bitmaps dos grupos de comandos suportados ou listas de métricas suportadas para um módulo local ou parceiro remoto selecionado. O software usa esses resultados antes de emitir operações ou interpretar medições.

As páginas padrão de identidade e status C M I S, as páginas V D M e as áreas de comando e payload C D B fornecem o contexto de gerenciamento. A sequência prática é identidade, capacidades, estado, medições e, depois, interpretação da integridade.
