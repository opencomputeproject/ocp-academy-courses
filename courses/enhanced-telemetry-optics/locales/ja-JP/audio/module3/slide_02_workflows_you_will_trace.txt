# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
このモジュールの終わりまでに、4段階のC D Bのワークフローを追跡できるようになります:コマンドメッセージの準備、コマンドのトリガー、ステータスレジスタのポーリング、そして応答の取得。

また、Page 9Fhや拡張ペイロードページの目的をバイトフィールドを暗記せずに説明することも可能です。

その後、コマンドワークフローをイベントログに接続します。イベントログは、即時の症状が過ぎた後も時間、アイデンティティ、イベントタイプを保持するため重要です。

最後に、リモートバイトアクセスとリモートページアクセスを区別します。どちらもローカル準拠モジュールを通じて遠端のエンドポイントに情報を提供する方法です。
ワークフローは低レベルに見えるかもしれませんが、ファームウェアエンジニアだけのものではありません。オペレーターは、ツールが正しく再試行されたり、故障を明確に報告したり、リンクが回復した後にイベントレコードを保持したりするときにその影響を感じます。
