# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
有用なイベントログには、詳しい情報と重複の抑制の両方が必要です。ノイズの多いリンクでは、同じ状態が繰り返され、循環バッファーが重複記録で上書きされることがあります。

仕様は、既定値10秒の設定可能なヒステリシスを使用します。これにより、異なるイベントを保持しながら、設定した間隔内の重複記録を制限します。

イベント定義は、モジュールの温度と電圧、光パワーのアラーム、リセット、受信機の信号またはロックの状態、エラー閾値、ファームウェアの変更、自律シャットダウンを対象にしています。すべての記録を単なるリンクアラームとして扱わず、イベント識別子と詳細フィールドをデコードしてください。

スコアの閾値とイベントを記録する条件は、目的が異なります。スコアの境界を変更すればすべてのイベント閾値も変わる、あるいはスコア計算からマスクしたカウンターはエビデンスとして使えなくなる、と考えてはいけません。

ホストAPIは、ローカルとリモートのエンドポイントに対して、イベントの取得とヒステリシスの制御を提供します。これらの制御を意図的に使い、照合の際にはモジュール時刻の有効性とシーケンスの情報を保持してください。

ヒステリシスは、障害の経緯を読み取りやすくするためのものです。ログの消去やカウンターのリセットの前に、インシデントを説明する記録を取得し、ホストのタイムラインとともに保存します。
