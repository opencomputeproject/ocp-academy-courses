# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
現在のテレメトリは、リンクの今の状態を示します。永続的なイベント記録は、その状態に至った経緯を説明するのに役立ちます。

イベントの各エントリーは32バイトです。16ビットのシーケンス識別子、ナノ秒単位の64ビットタイムスタンプ、イベント識別子、4つの詳細フィールド、予約領域を含みます。フィールドのバイト順はリトルエンディアンです。

イベント識別子によって、詳細のデコード方法が決まります。温度イベントには温度情報が含まれます。受信機イベントにはレーンのビットマップが含まれる場合があります。シャットダウンイベントには、側、ポート、発動したカテゴリ、メトリクス値が記録されます。

循環バッファーは、電源投入、取り外し、再挿入を経ても既存の記録を保持しなければなりません。シーケンス識別子は周回することがあるため、ソフトウェアは数値の大小だけで機械的に並べず、時系列の情報を保持する必要があります。

時刻にも前提があります。ナノ秒単位のタイムスタンプ形式は、ナノ秒の時計精度を保証しません。モジュール時刻を設定し、有効な時刻基準を設定する前に作成された記録を識別してください。

コマンド8010hは、ローカルまたはリモートの履歴を取得します。同じコマンドの別のオプションで履歴を消去します。永続的な記録は一過性の障害を説明する唯一の情報であることが多いため、消去前にエビデンスを読み取り、エクスポートしてください。
