# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
ホストSDKは、共通のモジュールインターフェースを運用のワークフローに変えます。仕様には、SONiCでの実装と、コマンドラインAPIのカテゴリが記されています。

ローカルとリモートのCMISアクセスで、レジスタ状態を取得します。テレメトリのダウンロードでは、選択したエンドポイント、側、ポートの測定値を表示します。イベントツールは、最近の履歴を読みやすい形式で取得し、ヒステリシスを制御し、意図した場合にのみ履歴を消去します。

ファームウェアツールは、適切なコマンド群と、確認済みのライフサイクル結果を使い、ローカルまたはリモートの保守を行います。モジュール時刻の制御は記録の比較に必要な基準を提供し、リンク評価の表示は、元のエビデンスを確認するための簡潔な入口になります。

検証と診断のツールには、機能検出、カウンターマスク制御、閾値制御、シャットダウン状態の確認も必要です。個々のユーザーインターフェースでの分類が異なっていても、これらの操作は下位のコマンドで定義されています。

読み取りと設定変更は、明確に区別してください。履歴の取得、履歴の消去、モジュールの応答方法の変更は、それぞれ異なる操作です。

有用なツールは、値とともに、宛先、対応機能、有効な設定、コマンド結果を報告します。この情報があることで、実際のインシデントでも出力を信頼できます。
