# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
フラグとマスクは、異なる問題を解決します。フラグは、報告された警告やアラームのどこに注意すべきかをソフトウェアに伝えます。マスクは、特定の累積カウンターを健全性スコアの計算に含めるかどうかを決めます。

推奨されるフラグ確認の手順は、ソフトウェア割り込みから始まります。次に、ローカルポートとリモートポートのフラグを区別するサマリーを読み、テレメトリ応答から、モジュール、光パワー、レーザーバイアスの詳細フラグを取得します。これらのフラグはラッチされ、レジスタの読み取り時にクリアされるため、収集ソフトウェアは観測した情報を保存しなければなりません。

定義されたスコアマスクは、FECカウンターとリンクダウンカウンターに適用されます。どちらも、モジュールの電源投入時はスコア計算から除外されます。マスクビットが1なら該当カウンターを除外し、0なら算入します。コマンド8003hでこれらのマスクを制御します。

マスクはエビデンスの削除ではありません。カウンターデータは引き続き取得でき、イベント履歴も別に存在します。累積カウンターのリセットには、別のコマンドを使用します。

モジュール間や異なる時点のスコアを比較するときは、有効なマスクを記録します。2つのツールが異なる算入設定を使っていれば、同じように見えるスコアでも、同じ運用状態を表しているとは限りません。
