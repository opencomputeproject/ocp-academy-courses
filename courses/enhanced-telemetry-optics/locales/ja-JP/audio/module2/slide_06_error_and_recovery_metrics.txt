# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
品質の測定値はマージンを示します。エラーと復旧の測定値は、そのマージンがサービスにどう影響するかを示します。

Pre-FEC BERは訂正前の誤りを表します。FECヒストグラムは、シンボル誤りの数に応じてフレームを分類します。誤りの多いビンから、受信機が厳しい動作条件に近づいているかが分かります。訂正不能コードワードは、訂正でデータを回復できない箇所を示します。

再リンク回数と稼働時間は、サービスの時間的な経過を補います。ノイズがあっても稼働し続けるリンクと、切断と再確立を繰り返すリンクは異なります。

LOS、すなわち信号喪失は、入力信号を検出できない受信機の状態を示します。DSPの詳細イベント定義では、LOLはロック喪失を意味します。ログをデコードするときは、この受信機の状態を、リンク全体のダウンイベントと区別してください。

現在の値を、時刻とイベント履歴に組み合わせます。短い誤りバースト、誤りの多いフレームの増加、再リンクの繰り返しは、それぞれ異なる運用状況です。

また、累積のFECビンカウンターとリンクダウンカウンターは、既定のマスクにより健全性スコアから除外されていても、エビデンスとして利用できます。値を取得できることと、スコアの計算に加わることは別の事実です。
