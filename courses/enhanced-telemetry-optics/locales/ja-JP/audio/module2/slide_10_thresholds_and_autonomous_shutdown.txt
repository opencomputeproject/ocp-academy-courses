# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
設定は、モジュールが状態を評価する方法と、その状態に応答する方法を変えます。この2つの選択を分けて考えてください。

閾値制御コマンド8004hは、FECビンレベル、pre-FEC BER、SNR、アイ高について、2つのスコア境界値を読み取り、設定します。この境界により、80、60、40のスコア帯が分かれます。

比較の方向はメトリクスによって異なります。BERは高いほど悪くなります。SNRとアイ高は高いほど良好です。閾値設定は選択したモジュールに適用されます。イベント表示や状態フラグは、このコマンドで設定可能なスコア閾値のカテゴリではありません。

自律シャットダウンは、コマンド8005hを使用します。モジュールリセットまたは電源リセット後は、既定で無効です。有効な状態で不健全な条件により発動すると、モジュールは異常状態に移行します。

モジュールは異常原因26hを報告し、イベント000Chを記録します。イベントの詳細から、影響を受けた側、データパスポート、発動したカテゴリ、メトリクス値が分かります。このエビデンスにより、設定による応答と原因不明のリンク切断を区別できます。

検証やインシデント分析の前に、有効な閾値とシャットダウン状態を読み戻してください。設定は背景情報ではなく、エビデンスの一部です。
