# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
テレメトリを解釈する前に、機能を検出します。未対応のフィールドや、到達できないリモートパートナーを、健全性を示すゼロとして表示してはいけません。

仕様v1.0.0で定義される動作は、Telemetry Version 2として通知されます。このプロトコル識別子は、ページ01hのバイト191で報告されます。文書のリリース番号とは異なります。

ソフトウェアは、帯域内通信の機能への対応と、通信レーンの確立状態も確認します。この2つは別の確認事項です。一部のモジュールは帯域内通信レーンの自動検出に対応し、高度テレメトリに対応しない相手とも基本的なリンクを確立できます。したがって、リンクアップだけではリモートの可視性を証明できません。

機能通知コマンド8000hは、ローカルモジュールまたは選択したリモートパートナーについて、対応コマンドグループのビットマップや、対応メトリクスの一覧を返します。ソフトウェアは、その結果を利用してから操作を実行し、測定値を解釈します。

標準のCMIS識別情報ページと状態ページ、VDMページ、CDBのコマンド領域とペイロード領域が、周辺の管理情報を提供します。実用的な順序は、識別情報、機能、状態、測定値、そして健全性の解釈です。
