# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
このモジュールのメトリクスは、リンクの状態を判断に結び付けます。

信号品質の測定値は、弱いインターフェースやレーンの特定に役立ちます。エラー、復旧、稼働時間のデータは、その弱点がサービスに影響しているかを示します。環境と識別情報のフィールドは、エビデンスを物理モジュールに結び付けます。

健全性スコアは、選択したホスト側またはメディア側で、対応するカテゴリスコアの最小値を取ります。最低カテゴリのビットマップは、同率で寄与するすべてのカテゴリを示します。カウンターマスクと設定された閾値から、そのサマリーがどのように計算されたかが分かります。

自律シャットダウンは、それとは別の、設定による応答です。リセット後は無効で、発動した場合は異常原因とイベントのエビデンスが残ります。スコアが低いことを、シャットダウンが有効だった、または実際に発生した証拠と混同してはいけません。

実務上の判断基準は、エビデンスが次の行動を絞り込めるかどうかです。光接続の点検、電気信号マージンの調査、熱の確認、ファームウェアの確認、監視の継続のどれを示唆しているでしょうか。次のモジュールでは、ソフトウェアがそれらの選択を裏付ける情報を要求し、保持する方法を学びます。
