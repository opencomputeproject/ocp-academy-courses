# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
ホストソフトウェアはリンクの各側面ごとに異なるメンタルモデルを必要としません。I二乗Cでローカルトランシーバーと通信します。そこからコマンドはローカルデータの要求を依頼するか、ローカルモジュールにインバンドインターフェースを通じてリモートリンクパートナーからデータを取得するよう求めることができます。

これは特にブレイクアウト事件で重要です。ローカルモジュールは複数のリモートパートナーを持つ場合があるため、リクエストは適切なデータを返すために十分なエンドポイントコンテキストを保持しなければなりません。

オペレーターにとっての利点は一貫性にあります。ホストは制御点のままです。ローカル準拠モジュールがリモート可視化への架け橋となります。これが、次に見直す多くの指標の背後にある運用モデルです。
このモデルはまた、工具が断片化するのを防ぎます。ローカルクエリとリモートクエリがワークフローを共有している場合、ホストソフトウェアは、データソースがリンクの反対側にあっても一貫したオペレーター体験を提供できます。
