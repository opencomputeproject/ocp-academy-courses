# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
Scopeはここで有益な仕事をしています。この仕様は準拠の400G、800G、1.6Tトランシーバーに適用され、モジュールP M Dや物理メディア依存の実装に依存しないものであることを意図しています。言い換えれば、テレメトリインターフェースは単一の光学実装の詳細に依存してはなりません。

この仕様はまた、C M I S、すなわちOIFの共通管理インターフェース仕様を基にしています。C M I Sの代わりにはなりません。C M I Sの機能を使用し、特定の定義や修正を加えて、光学系テレメトリが運用上の質問により一貫して答えられるようにしています。

除外も重要です。テレメトリサーバーはスコープ外です。これにより、オペレーターはモジュールとホストデータを独自の観測スタックに統合し、トランシーバ境界の共通インターフェースを弱めることなく管理できます。
スコープコントロールは弱点ではありません。それこそが貢献を実行可能にしているのです。インターフェースを標準化しつつ、高レベルのサーバー設計を開放することで、モデルは1つの観測可能性スタックを強制することなく、異なるオペレーター環境に適合させることができます。
