# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
最初のモジュールは、残りのコースのメンタルモデルを示しています。強化型テレメトリは、局所警報とそれを説明する遠隔またはセグメント固有の証拠との間の可視性ギャップを埋めようとしています。

標準化された作業はトランシーバーとホストインターフェースにあります。テレメトリサーバーはオペレーターによって異なる場合がありますが、スイッチソフトウェアが有用なデータを収集できるように、モジュールは共通の動作が必要です。

二つの詳細が何度も浮かび上がるでしょう。まず、準拠光学はローカルおよび遠隔のテレメトリを収集します。次に、リンクは複数の監視されたセグメントや複数のリモートパートナーを含む場合があります。次のモジュールでは、そのモデルをオペレーターが使用できる特定の指標、フラグ、リンク健康スコアに変換します。
復習のために、以降のすべての機能をこの共有モデルに結びつけてください。もしメトリクス、イベント、コマンド、またはAPIがリンク条件の特定や説明に役立たなければ、それはおそらくコアレッスンではなく、詳細を補完しているだけです。
