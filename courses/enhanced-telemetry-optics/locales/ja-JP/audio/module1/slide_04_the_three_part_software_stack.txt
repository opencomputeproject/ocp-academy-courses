# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; DSP -> D S P; SDK -> S D K; API -> A P I
信頼性を支える共通のワークフローには、3つの層があります。トランシーバーは、ファームウェア、測定、イベント履歴、そしてローカルとリモートのエビデンスを提供するために必要なコマンド動作を実装します。

通常はスイッチ上で動作するホストソフトウェアは、モジュールが対応する機能を検出し、データを要求し、コマンドの結果を確認して、運用ツール向けの出力を準備します。要求した情報がリモートのリンクパートナーから得られる場合でも、ホストはローカルの制御点であり続けます。

その上位では、テレメトリサーバーのソフトウェアがネットワークの健全性を集約し、要約し、報告できます。その実装はオペレーターに委ねられています。仕様が定義するのは、必須の監視サーバー設計を1つに定めることではなく、モジュールの動作と共通のホストインターフェースです。

この役割分担は、システムの統合時に重要です。ベンダーがモジュールのインターフェースを実装し、スイッチの担当チームがテレメトリの収集を実装し、オペレーターが導入環境に合う集約ツールを選択できます。共通の境界があることで、これらの選択を組み合わせて機能させられます。

インシデントの際も、同じ層を順にたどります。エビデンスがモジュール内に存在するか、ホストがそれを正しく取得したか、そして監視システムがそのコンテキストを保持したかを確認してください。
