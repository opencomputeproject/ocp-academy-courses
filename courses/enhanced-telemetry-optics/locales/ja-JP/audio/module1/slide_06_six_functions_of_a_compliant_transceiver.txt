# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
概要では、覚えておくべき6つの機能が示されています。まず、準拠トランシーバーはミッションモードでリンクを監視し、リンクが有用な作業をしている間にモジュールが統計を収集します。

次に、モジュールは共通の指標を通じてリンク健全性を報告し、時間経過でテレメトリを追跡します。第三に、モジュールは透過的な帯域内通信をサポートしており、リンクの両端が互いを識別し、データを交換できます。

第四に、モジュールは非揮発性メモリにイベントを通知し記録できます。第五に、ローカルおよびリモートのトランシーバーで無停止ファームウェア更新をサポートしています。第六に、スイッチソフトウェアはモジュールテレメトリを収集し、サーバーへのストリーミング準備を可能にします。

これらの機能は連鎖として覚えやすいです。測定、スコアリング、最終点への到達、ストーリーの保存、安全な更新、そして運用システムへの供給。
これらの機能のどれも単独では成立しないことに注目してください。ログを取らずにモニタリングすると履歴が失われます。リモートアクセスなしでログを記録すると、エンドポイントのコンテキストが失われます。ファームウェア更新の状態フィードバックがなければリスクが高まります。信頼性は関数同士が連携して働くことから生まれます。
