**標題**\
增強型光學遙測

**簡短說明**\
運用光學指標、事件歷史、遠端存取與韌體工作流程，評估鏈路健康狀況與部署就緒程度。

**完整說明**

探索增強型光學遙測如何協助維運人員在 AI 網路中判斷發生了什麼故障、故障位於何處，以及哪些證據能支持下一步行動。將鏈路健康指標與旗標連結到命令工作流程、持久保存的事件歷史、遠端存取、韌體管理與主機軟體，建立診斷光鏈路及評估部署就緒程度的實用模型。

**總學習時間：50 分鐘**

**模組 1：AI 網路的可見性難題（10 分鐘）**\
從整體網路規模理解鏈路可靠性，釐清軟體與收發器的職責，並在遙測模型中區分本地、遠端與分支連接端點。

**模組 2：指標、旗標與鏈路健康狀況（14 分鐘）**\
將指標區分為品質、錯誤、恢復、環境與脈絡類別，並解讀鏈路健康評分、旗標、遮罩、臨界值與自主關閉行為。

**模組 3：CDB 工作流程、事件日誌與遠端存取（14 分鐘）**\
追蹤經過檢查的命令資料區塊交換與持久事件日誌，區分遠端位元組存取與頁面存取，並將取得的證據用於故障調查。

**模組 4：韌體、主機軟體與部署就緒（12 分鐘）**\
檢視韌體維護、模組時間關聯、主機測量與命令列 API 類別，將遙測收集、伺服器彙整與部署就緒檢查連結起來。
