# TTS note: pronounce FEC as "feck"; preserve official technical acronyms.
主机 SDK 将通用模块接口转化为运维工作流。规范描述了 SONiC 实现和一组命令行 API 类别。

本地与远程 CMIS 访问提供寄存器状态。遥测下载显示所选端点、接口侧与端口的测量值。事件工具以可读形式获取近期历史，控制滞回，并且只在明确需要时清除历史。

固件工具使用相应命令族和经过检查的生命周期结果，处理本地或远程维护。模块时间控制提供比较记录所需的时间参考，链路评分显示则提供简明的入口，供运维人员深入查看底层证据。

资格验证和诊断工具还需要能力发现、计数器掩码控制、阈值控制与关断状态核实。即使某个用户界面采用不同的功能分组，这些操作仍由底层命令定义。

要明确区分读取与配置更改。获取历史、清除历史，以及改变模块响应方式，是不同的操作。

实用的工具会在报告数值的同时，提供目标、支持能力、生效配置和命令结果。正是这些上下文，使输出在真实故障中值得信赖。
