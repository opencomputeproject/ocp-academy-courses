# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
El módulo dos convierte el modelo de visibilidad en mediciones. La especificación enumera la telemetría que un transceptor compatible debe poner a disposición del host, ya sea localmente o desde socios de enlace remotos a través de la interfaz de mensajería en banda.

Agruparemos esos campos en categorías operativas: calidad óptica, calidad eléctrica, errores, comportamiento de recuperación, contexto ambiental e identidad administrativa. Luego conectaremos las categorías con banderas, mascarillas y la puntuación de salud-enlace.
Piensa en este módulo como construir un vocabulario de panel. Los valores son técnicos, pero el objetivo es operativo: separar los problemas de márgenes de los problemas de servicio, y separar los síntomas locales de las causas remotas o específicas de segmento.
