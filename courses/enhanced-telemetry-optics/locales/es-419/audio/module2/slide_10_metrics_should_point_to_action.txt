# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I al cuadrado C; VDM -> V D M; SNR -> S N R; FEC -> F E C; BER -> B E R; DSP -> D S P; API -> A P I
Las métricas de este módulo convierten el estado del enlace en una decisión.

Las mediciones de calidad de señal ayudan a localizar la interfaz o el carril débil. Los datos de errores, recuperación y tiempo de actividad muestran si esa debilidad afecta al servicio. Los campos ambientales y de identidad vinculan la evidencia con el módulo físico.

La puntuación del estado es el mínimo de las puntuaciones de las categorías compatibles del lado seleccionado, sea el del host o el del medio. El mapa de bits de las categorías más bajas identifica todas las que empatan. Las máscaras de contadores y los umbrales configurados explican cómo se calculó ese resumen.

El apagado autónomo es una respuesta configurada independiente. Comienza desactivado después de un reinicio y, cuando se activa, deja evidencia de falla y de evento. No confunda una puntuación baja con la prueba de que el apagado estaba habilitado o se produjo.

La prueba práctica es si la evidencia acota el siguiente paso. ¿Sugiere inspección óptica, investigación del margen eléctrico, comprobaciones térmicas, revisión del firmware o continuar el monitoreo? El siguiente módulo muestra cómo el software solicita y conserva la información que respalda esas decisiones.
