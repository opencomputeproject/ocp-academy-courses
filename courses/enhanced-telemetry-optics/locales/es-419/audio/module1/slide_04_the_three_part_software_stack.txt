# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I al cuadrado C; VDM -> V D M; SNR -> S N R; FEC -> F E C; BER -> B E R; DSP -> D S P; API -> A P I
Un flujo común de fiabilidad tiene tres capas. El transceptor implementa el firmware, las mediciones, el historial de eventos y el comportamiento de comandos necesario para exponer evidencia local y remota.

El software del host, normalmente en un switch, descubre las capacidades del módulo, solicita datos, comprueba los resultados de los comandos y prepara la salida para las herramientas operativas. El host sigue siendo el punto de control local, incluso cuando la información solicitada proviene de un extremo remoto.

Por encima, el software del servidor de telemetría puede compilar, resumir e informar el estado de la red. Su implementación depende del operador. La especificación define el comportamiento del módulo y la interfaz común del host, no un diseño obligatorio de servidor de monitoreo.

Esta división importa durante la integración. Un proveedor puede implementar la interfaz del módulo; un equipo de switches, la recopilación; y un operador, las herramientas de agregación adecuadas para su despliegue. El límite compartido permite que esas decisiones funcionen juntas.

Durante un incidente, siga las mismas capas. Pregunte si la evidencia existe en el módulo, si el host la recuperó correctamente y si el sistema de monitoreo conservó el contexto.
