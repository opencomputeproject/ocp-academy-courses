# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I al cuadrado C; VDM -> V D M; SNR -> S N R; FEC -> F E C; BER -> B E R; DSP -> D S P; API -> A P I
Un enlace es más que la fibra entre dos módulos. Hay tres regiones de interfaz: la conexión eléctrica entre el switch y el módulo, la conexión óptica entre los módulos y la conexión eléctrica entre el módulo y el servidor.

El tráfico circula en ambas direcciones, por lo que la especificación describe seis segmentos direccionales. Cada receptor observa una señal entrante concreta. Un mal resultado en un receptor no identifica automáticamente al transmisor, la fibra o la interfaz eléctrica como causa.

Esta distinción explica por qué la telemetría del módulo y las mediciones del receptor del host deben utilizarse juntas. El switch también registra su propia B E R previa a F E C y las palabras de código no corregibles. La telemetría remota permite examinar el módulo del otro extremo, incluso cuando el operador no puede acceder directamente al servidor.

La animación agrupa las seis direcciones en las tres regiones de interfaz. Use esta vista para organizar la investigación y compare las mediciones de los receptores pertinentes.

Si los síntomas no coinciden, conserve esa discrepancia como evidencia. Una alarma local, un evento remoto y un patrón de errores del host pueden describir partes distintas de la misma falla. La identidad del segmento hace útiles esas observaciones.
