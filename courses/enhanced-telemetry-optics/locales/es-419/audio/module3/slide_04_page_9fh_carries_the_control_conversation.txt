# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
La página 9Fh es donde está la conversación sobre el control. La especificación apunta a la página de mensajería C M I S C D B e identifica los campos de encabezado de comando, los campos de encabezado de respuesta y el área local carga útil.

Para los cursos académicos, no necesitamos enseñar cada byte. El concepto duradero es la separación de roles. El host escribe el comando. El módulo informa del estado y devuelve la respuesta. El área carga útil transporta los datos que pertenecen a esa petición.

Esto es importante porque muchas herramientas de operador dependen finalmente de la misma disciplina de nivel inferior. Si el software omite la comprobación de estado o lee la respuesta demasiado pronto, corre el riesgo de convertir un modelo de comandos estructurado en una salida de depuración poco fiable.
Este es un buen lugar para separar el detalle de implementación del detalle de aprendizaje. Los ingenieros que implementan la interfaz necesitan los mapas de bytes. Los aprendices que operan el sistema necesitan saber qué están organizando los mapas de bytes.
