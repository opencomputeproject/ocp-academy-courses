# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I squared C; SONiC -> sonic; PMD -> P M D; VDM -> V D M; DDMI -> D D M I; SNR -> S N R; PAM4 -> PAM four; MPI -> M P I; FEC -> feck; BER -> B E R; LOS -> L O S; LOL -> L O L; SDK -> S D K; API -> A P I
El módulo tres pasa de lo que se mide a cómo lo obtiene el host. La especialización utiliza C D B, o Bloque de Datos de Comando, para el intercambio comando-respuesta entre host y el módulo.

Mantendremos el nivel conceptual. Necesitas entender el flujo de trabajo de preparar, activar, sondear y recuperar. También necesitas entender por qué la comprobación de estado, los registros de eventos, el acceso remoto C M I S y la gestión carga útil son relevantes para operaciones fiables.
Si el módulo dos era el vocabulario, este módulo es la gramática. C D B define cómo se estructuran las solicitudes y respuestas para que software del host pueda solicitar datos repetidamente e interpretar el resultado con confianza.
