# pronunciation: CMIS -> C M I S; CDB -> C D B; I2C -> I al cuadrado C; VDM -> V D M; SNR -> S N R; FEC -> F E C; BER -> B E R; DSP -> D S P; API -> A P I
El SDK del host convierte la interfaz común del módulo en flujos de trabajo operativos. La especificación describe una implementación SONiC y varias categorías de A P I de línea de comandos.

El acceso C M I S local y remoto expone el estado de los registros. La descarga de telemetría muestra mediciones para un extremo, lado y puerto seleccionados. Las herramientas de eventos recuperan el historial reciente en formato legible, controlan la histéresis y borran el historial solo de manera deliberada.

Las herramientas de firmware gestionan el mantenimiento local o remoto con la familia de comandos adecuada y resultados verificados del ciclo de vida. Los controles de hora del módulo aportan la referencia para comparar registros, mientras que la puntuación del enlace ofrece un punto de entrada conciso a la evidencia subyacente.

Las herramientas de calificación y diagnóstico también necesitan descubrimiento de capacidades, control de máscaras de contadores, control de umbrales y verificación del estado del apagado. Los comandos de bajo nivel definen esas operaciones, aunque una interfaz concreta las agrupe de otra forma.

Distinga claramente las lecturas de los cambios de configuración. Recuperar historial, borrarlo y cambiar cómo reacciona el módulo son acciones diferentes.

Una herramienta útil informa el destino, la capacidad compatible, la configuración efectiva y el resultado del comando junto con el valor. Ese contexto hace fiable la salida durante un incidente real.
