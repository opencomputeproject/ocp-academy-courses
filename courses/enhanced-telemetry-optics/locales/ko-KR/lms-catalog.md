**과정명**\
향상된 광학 텔레메트리

**짧은 설명**\
광학 지표, 이벤트 이력, 원격 접근 및 펌웨어 워크플로우를 활용하여 링크 상태와 배포 준비도를 평가합니다.

**상세 설명**

향상된 광학 텔레메트리가 AI 패브릭에서 무엇이 어디서 고장 났는지, 그리고 어떤 증거를 바탕으로 다음 조치를 결정할 수 있는지 파악하는 데 어떻게 도움이 되는지 살펴봅니다. 링크 상태 지표와 플래그를 명령 워크플로우, 영속적인 이벤트 이력, 원격 접근, 펌웨어 관리 및 호스트 소프트웨어와 연결합니다. 광 링크를 진단하고 배포 준비도를 평가하기 위한 실용적인 모델을 익힙니다.

**총 학습 시간: 50분**

**모듈 1: AI 패브릭 가시성 문제 - 10분**\
패브릭 규모에서 링크 신뢰성을 이해하고, 소프트웨어와 트랜시버의 역할을 식별하며, 텔레메트리 모델에서 로컬, 원격 및 브레이크아웃 엔드포인트를 구분합니다.

**모듈 2: 지표, 플래그, 링크 상태 - 14분**\
품질, 오류, 복구, 환경 및 맥락 지표를 분류합니다. 링크 상태 점수, 플래그, 마스크, 임계값 및 자율 종료 동작을 해석합니다.

**모듈 3: CDB 워크플로우, 이벤트 로그, 원격 액세스 - 14분**\
상태를 확인하는 Command Data Block 교환과 영속적인 이벤트 로그를 추적합니다. 원격 바이트 접근과 페이지 접근을 구분하고, 수집한 증거를 장애 조사에 연결합니다.

**모듈 4: 펌웨어, 호스트 소프트웨어, 배포 준비 - 12분**\
펌웨어 유지보수, 모듈 시간 상관관계, 호스트 측정값 및 명령줄 API 범주를 살펴봅니다. 텔레메트리 수집과 서버 집계를 배포 준비도 점검에 연결합니다.
