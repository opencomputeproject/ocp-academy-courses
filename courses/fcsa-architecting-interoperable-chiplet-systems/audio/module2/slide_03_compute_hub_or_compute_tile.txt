# pronunciation: F C S A; input output; nonvolatile memory; chiplet root of trust for attestation.

Compare the responsibilities, not just the arrangement of rectangles. A Compute and Hub system requires at least one Compute One chiplet and at least one Hub chiplet. Compute One supplies application processing. The Hub provides access to system memory and input-output resources. A primary Hub coordinates system management and security when there are several Hubs. In a Compute Tile system, at least one Compute Two chiplet combines application processing with direct access to memory and input-output resources. With several Compute Two chiplets, one is primary and coordinates those system functions. The contrast is not an absolute ban on other capabilities: Compute One can also contain or directly connect to system memory, and implementations can satisfy multiple types. Start with the required roles, then inspect each chiplet's capabilities and required interfaces. A familiar-looking topology alone does not establish the classification.
