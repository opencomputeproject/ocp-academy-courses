# pronunciation: F C S A; input output; nonvolatile memory; chiplet root of trust for attestation.

Start with a system design whose processing, memory, and control functions were planned together. Partition that design across chiplets, and some relationships that were internal now cross independently designed boundaries. A working physical link does not settle what each chiplet provides, what its neighbor expects, or how the complete system behaves. F C S A makes those expectations explicit through system types, chiplet types, and interface requirements. Protocol and transport mappings add implementation detail where suitable standards exist; some mappings remain to be defined. Now reuse the same compute chiplet in another configuration. Its identity stays the same, but the surrounding system changes. The integrator must check the applicable roles and interfaces again. Design and profile requirements add the detail needed for the intended product. Reuse therefore begins with a shared architectural contract; it does not end with a connection.
