# pronunciation: F C S A; input output; nonvolatile memory; chiplet root of trust for attestation.

Matching chiplet types is only the start of an integration review. Follow a memory transaction between two chiplets whose interconnect properties differ, such as address-field or identifier-field width. The transaction must be adapted as needed before it crosses the chiplet memory traffic interface. The relevant protocol determines the adaptation; changing the drawing's field shape does not authorize dropping information. The differences must not prevent transmission or reception, or the required performance of related system functions. Those requirements need evidence for the actual design. Now widen the view. A snoop filter can serve coherent caches on several chiplets. Adding a requester chiplet changes the combined demand that its capacity must support. A chiplet-local capacity statement is therefore insufficient. Evaluate the participating system together. F C S A places transaction adaptation in Level One and the combined snoop-filter capacity rule in Full compliance.
