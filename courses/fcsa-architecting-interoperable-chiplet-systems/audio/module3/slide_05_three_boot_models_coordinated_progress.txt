# pronunciation: F C S A; input output; nonvolatile memory; chiplet root of trust for attestation.

Follow the second-stage boot image, then ask who controls progress. In distributed boot, the manager fetches both images from one nonvolatile memory and loads the subordinate's image into that component. In shared boot, each component fetches its own image from the same memory. Sequence control manages access and controls when images execute. In independent boot, each component loads from separate memory, potentially in parallel. The components still synchronize; separate storage does not remove coordination. Ready to proceed and Error travel from subordinate to manager. Proceed travels back. Depending on the model and step, those signals govern loading, execution, or synchronization. Keep the image path separate from permission to advance. An error reports a loading or verification problem; it is not permission to continue. These examples concern second-stage boot. The signals alone neither authenticate the firmware nor define a complete boot protocol.
