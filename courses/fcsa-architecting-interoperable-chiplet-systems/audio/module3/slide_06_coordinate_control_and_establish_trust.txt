The System Control Framework performs low-level system management, including power and thermal management. One primary system controller coordinates secondary system controllers. A controller sets policy within its scope, while system control agents implement policy directly or locally. These roles explain how a distributed system can coordinate actions without making every chiplet an equal policy authority.

Trusted Security Agents provide a different set of functions. They implement hardware-enforced security responsibilities and the security-platform roles used to establish and maintain trust. Both control and security components can execute firmware and participate in boot, but a shared implementation technology does not make their architectural responsibilities identical. A power-state decision is not itself an attestation decision.
