# pronunciation: F C S A; input output; nonvolatile memory; chiplet root of trust for attestation.

Disaggregation changes the places where identity, state, and responsibility must be established. This module explains F C S A's chiplet-system security model and applies it to two integration risks. The objective is system security comparable to the monolithic case, evaluated in product context. The chapter is a starting point for that analysis, not a certificate that any selected composition is secure.
