Com essa perspectiva de sistemas estabelecida, as unidades de processamento quântico são mais fáceis de posicionar se pensarmos em termos de especialização.

Um CPU ainda é o orquestrador de uso geral. Ele lida com o fluxo de controle, sistemas operacionais, escalonamento e lógica ampla de aplicação.

Um GPU é um acelerador massivamente paralelo. É forte onde o trabalho pode ser expresso como muitas operações matemáticas semelhantes, como matemática tensorial, simulação e outras cargas de trabalho aceleradas.

Um QPU é diferente novamente. Ele executa circuitos quânticos, onde o recurso útil é o próprio comportamento quântico. Isso o torna relevante para classes de problemas restritos, como certas simulações, abordagens de otimização, química, materiais e pesquisa em algoritmos quânticos.

O futuro prático não é um processador substituir todos os outros. É um sistema heterogêneo onde cada motor realiza o trabalho para o qual é adequado.

Esse modelo de especialização é o mesmo motivo pelo qual as GPUs não fizeram as CPUs desaparecerem. GPUs expandiram o que os sistemas podiam fazer ao acelerar o tipo certo de trabalho. CPUs continuaram essenciais para orquestração e lógica geral.

A integração de QPU deve ser interpretada da mesma forma. Se processadores quânticos se tornarem úteis em data centers, provavelmente aparecerão como recursos especializados anexados a sistemas clássicos. A relevância óptica vem da necessidade de mover informações, temporização e sinais de controle de forma confiável através dessa arquitetura híbrida.
