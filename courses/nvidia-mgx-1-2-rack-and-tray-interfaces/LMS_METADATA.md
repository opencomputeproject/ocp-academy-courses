# NVIDIA MGX 1.2 Rack and Tray Interfaces

## Short description

Review MGX 1.2 rack, tray, power, and cooling interfaces through source drawings, CAD motion, and acceptance evidence.

## Long description

Mechanical, electrical, liquid, and module interfaces for deep technical integration reviews.

Total narrated runtime: 64.7 minutes. Allow additional time for knowledge checks, review, and learner interaction.

Module 1: Rack geometry, datums, and alignment (11 min narrated)
Trace the mechanical interface chain from rack frame to tray and cartridge, and distinguish controlling dimensions from implementation choices.

Module 2: Tray architecture, board envelopes, and DC-SCM (11 min narrated)
Interpret hybrid and fanless examples, board mounting and keepout rules, and the MGX management-module interface.

Module 3: Modular I/O bay dimensions and retention (11 min narrated)
Decode bay locations, compare A-E envelopes and depth variants, and verify retention and fanless interface dimensions.

Module 4: Busbar electrical design and grounding (10 min narrated)
Interpret the current/voltage envelope, grounding variants, layered busbar construction, and electrical acceptance evidence.

Module 5: Liquid cooling and blind-mate mechanics (11 min narrated)
Trace the fluid interfaces and thermal boundaries, and explain float, preload, overdrive, leakage controls, and wetted-material requirements.

Module 6: Load cases, qualification, and integration review (11 min narrated)
Interpret documented connector-force cases and build a source-linked acceptance review for a selected MGX implementation.

Planned learner time: about 90 minutes. Narration durations are rounded to the nearest minute.
