Depth compatibility has a direction. A short bay can be used in a location designated for a short or a long bay. A long bay can only be used in a long location. It cannot be accepted in a short-only location by appealing to the modular family name.

The standard short bay has a maximum depth of one hundred thirty-two point eight millimeters. The long bay maximum is three hundred eighteen millimeters. The comparison illustrates the space relationship, but the controlling statement is the allowed location class. Retention and connections must still be present for the selected implementation.

Type C also has a C R P S optimized short option. C R P S means common redundant power supply. Its maximum depth is one hundred eighty-five millimeters, reflecting the power-supply use described in the contribution. This is a separately specified option, not a change to the generic one hundred thirty-two point eight millimeter short envelope.

When reviewing a population, write the complete depth choice. Short, long, and the Type C optimized variant must not collapse into a single label. A proposed one hundred eighty-five millimeter assembly therefore needs evidence that its actual location supports that variant.
