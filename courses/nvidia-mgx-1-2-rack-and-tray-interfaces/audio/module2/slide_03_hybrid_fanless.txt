# pronunciation: MGX -> M G X; HPM -> H P M; DC-SCM -> D C S C M; DC-SCI -> D C S C I; UQD -> U Q D; UQDB -> U Q D B; MQD -> M Q D; MQDB -> M Q D B; RU -> rack unit; PCIe -> P C I Express; PG25 -> P G twenty-five; Hi-Pot -> high-pot; CRPS -> C R P S; versions and technical quantities spelled out.
A tray substitution must preserve more than the outside dimensions. The contribution defines a compute tray as a one-rack-unit chassis containing a central or graphics processing element. A switch tray contains the switching devices and interconnects for a multi-node network. Both use the M G X reference chassis.

The fanless compute tray uses the same outer chassis dimensions as that reference, but it does not retain all the same mounting-feature details. That distinction is explicit. Don't infer internal interchangeability solely from a shared width, height, and depth.

In the hybrid example, component placement includes an air-cooling fan zone and liquid-cooled processing regions. A host processor module, abbreviated H P M, is the processor-board assembly whose envelope and interfaces are controlled as part of the system.

The fanless tray performs one hundred percent of its tray cooling through the liquid loop. Fans are no longer needed or supported in this design. The removed fan zone creates opportunities for larger modules, integrated liquid distribution, and blind-mate input and output arrangements.

Those opportunities do not mandate one population. The contribution shows implementation examples, and their mounting features must be read in that context. During review, separate the common outer chassis boundary from the actual mounting, cooling, and connection features of your assembly. Ask whether the changed module preserves those interfaces, and whether its liquid-cooling implementation meets the conditions relevant to the complete tray. The rack-level heat-capture measure will be examined separately later in the course.
