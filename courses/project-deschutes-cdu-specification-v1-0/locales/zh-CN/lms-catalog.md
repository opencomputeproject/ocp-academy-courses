**标题**\
OCP Project Deschutes：冷却液分配单元（CDU）规范 v1.0

**简短描述**\
了解 Deschutes CDU 的架构、性能、控制、可维护性、部署方式及合格供应链。

**详细描述**

本课程介绍 OCP Project Deschutes 和《冷却液分配单元（CDU）规范 v1.0》。了解 CDU 在设施供水回路与设备冷却回路之间的位置，解读其机械和热性能，并审视控制、电气接口及可维护性。结合部署案例与供应商模式，明确实施和持续运行所需的依据。

**总学习时长：40 分钟**

**模块 1：为什么Deschutes，为什么是现在（10 分钟）**\
介绍冷却挑战与 Deschutes 架构。追踪设施供水经过 CDU 进入设备冷却系统（TCS）的路径，并结合应用背景理解主要性能规格。

**模块 2：CDU 架构与性能（17 分钟）**\
考察外形尺寸、接头、泵、换热器、传感器、控制系统及供电接口。解读已发布的流量和热性能条件，以及便于维护的设计要求。

**模块 3：部署、供应链与行动号召（13 分钟）**\
将热通道封闭和机架供电案例与部署决策联系起来。了解供应商资质认定、现场可更换单元（FRU）、隔离与维护步骤，以及参与项目的资源。
