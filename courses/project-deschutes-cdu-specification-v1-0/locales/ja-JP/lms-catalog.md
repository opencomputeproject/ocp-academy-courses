**タイトル**\
OCP Project Deschutes：冷却液分配ユニット（CDU）仕様 v1.0

**短い説明**\
Deschutes CDUの構成、性能、制御、保守性、導入方法、認定サプライチェーンを学びます。

**詳しい説明**

OCP Project Deschutesと冷却液分配ユニット（CDU）仕様 v1.0を取り上げます。設備側の水ループとIT機器側の冷却ループの間に位置するCDUの役割を理解し、機械・熱性能を読み解きます。制御、電気インターフェース、保守性を確認し、導入事例とサプライヤーモデルを実装と継続運用に必要な根拠に結び付けます。

**総学習時間：40分**

**モジュール1：なぜDeschutes、なぜ今なのか（10分）**\
冷却の課題とDeschutesのアーキテクチャを紹介します。設備側の水がCDUを経て技術冷却システム（TCS）に至る流れを追い、主要な性能仕様を文脈の中で捉えます。

**モジュール2：CDU アーキテクチャとパフォーマンス（17分）**\
外形寸法、継手、ポンプ、熱交換器、センサー、制御系、給電系を確認します。公開されている流量・熱性能の条件と保守性に関する設計を読み解きます。

**モジュール3：展開、サプライチェーンおよび行動喚起（13分）**\
ホットアイルコンテインメントとラック給電の事例を導入判断に結び付けます。サプライヤーの認定、現場交換可能ユニット（FRU）、隔離・保守手順、参加のための資料を確認します。
