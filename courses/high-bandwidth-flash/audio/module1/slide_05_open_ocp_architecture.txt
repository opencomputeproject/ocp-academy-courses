Version zero point seven point zero defines a high-level Base die architecture rather than one vendor's complete product. That scope reflects the O C P tenets. Openness makes the interface available for adoption. Impact addresses the memory wall. Scale comes from a repeatable multi-channel design. Efficiency comes from placing high-capacity memory near the X P U. Sustainability comes from reducing the need to add G P Yous only to obtain more memory capacity.

The specification is still an early version. Some fields remain product-specific, optional, or scheduled for later refinement. The value of an open workstream is that implementers can improve those boundaries together while software and hardware ecosystems develop around the same architectural model.
