# pronunciation: HPM -> H P M; MHS -> M H S; CCI -> C C I; KOZ -> keep out zone; DC-SCM -> D C S C M; CFF -> C F F; PCIe -> P C I Express; NIC -> Nick; HSIO -> high speed I O; PICPWR -> pick power; PCB -> P C B; M-PIC -> M Pick; M-XIO -> M X I O; M-PNP -> M P N P

Orient the model before measuring anything. The imported assembly uses its own three-dimensional coordinates. The specification's datum and primary-side view define the reference you need for the board review. A model axis or the corner of a screenshot isn't automatically that datum.

The animation uses the supplied Class L STEP assembly. It contains board and connector geometry, not a complete populated computer or chassis. Locate the near-side datum reference first. Then inspect the mounting and alignment features, the chassis-retention interface, and the handle-hole interface near the far edge. Use the actual published hole details to evaluate size, pad and keep out requirements.

Required and recommended holes serve different purposes. Additional mounting holes must use the standard mounting-hole requirements. Fixed risers introduce conditional retention-hole obligations. The handle-hole interface is required even though the designer may choose a handling solution that doesn't install a handle in that hole.

The source also permits localized negative board features, such as notches. Those features can't compromise required interfaces or remove a whole side edge to create a nonstandard width. A system that depends on a particular notch can lose compatibility with other compliant boards.

For Class L, the compliance table and body disagree on a near-side hole count. Record that conflict rather than choosing whichever number matches your model. A useful C A D observation supports the review; it doesn't settle conflicting normative text.
