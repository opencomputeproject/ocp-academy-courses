# pronunciation: HPM -> H P M; MHS -> M H S; CCI -> C C I; KOZ -> keep out zone; DC-SCM -> D C S C M; CFF -> C F F; PCIe -> P C I Express; NIC -> Nick; HSIO -> high speed I O; PICPWR -> pick power; PCB -> P C B; M-PIC -> M Pick; M-XIO -> M X I O; M-PNP -> M P N P

The primary-side height rules are conditional, so start by identifying what the system actually implements. The twelve millimeter zone is strongly recommended to support common thermal and cable arrangements. Exceeding it can reduce compatibility, but the source doesn't make it the same kind of universal requirement as every mandatory clearance.

The eleven point three millimeter zone becomes required when P C I Express Card Electromechanical, or C E M, cards sit directly above the H P M and its peripherals. The source includes qualifications and exemptions, including the compact secure-control module. The six millimeter zone is required when P C I Express risers are implemented, protecting their mechanical interface.

These restrictions apply to soldered board components, mated connector heights and the specified mated assemblies. They don't automatically apply in the same way to later-added heatsinks, shrouds or other mechanical parts. That distinction doesn't remove the system designer's responsibility to check those parts for collision.

Some connector and plug arrangements have explicit exceptions. Review the complete condition and actual mated height instead of comparing only an unmated receptacle with a zone number. Your finding should name the configuration, the applicable limit, any supported exception, and the clearance evidence still required. This makes a conditional rule usable without overstating it.
