# pronunciation: HPM -> H P M; MHS -> M H S; CCI -> C C I; KOZ -> keep out zone; DC-SCM -> D C S C M; CFF -> C F F; PCIe -> P C I Express; NIC -> Nick; HSIO -> high speed I O; PICPWR -> pick power; PCB -> P C B; M-PIC -> M Pick; M-XIO -> M X I O; M-PNP -> M P N P

High-speed input and output can use board-to-board, board-to-cable or hybrid connections. A hybrid interface combines direct board connections with cable connections. The same system-level purpose can therefore use different physical arrangements.

Table six identifies the compliant connector families. Near-side fixed risers use S F F T A ten thirty-three with a twenty-one ampere power block. Other high-speed interfaces can use the listed ten sixteen, ten twenty-six or ten thirty-three families, subject to the Extensible I O specification, known as M X I O. A familiar connector shape by itself doesn't establish the correct pinout or interface.

When near-side fixed risers are implemented, their defined locations apply. Full population of every location isn't required. The source illustrates alternative compliant choices that can demand more work from an ecosystem chassis. Keep that adoption effort separate from whether a particular requirement is mandatory.

For other high-speed connectors, this base specification doesn't fix every location or quantity. Placement must still respect required features and height restrictions. The riser board, endpoint and cable implementation need their own evidence. Record the exact connector variant, mated arrangement, electrical baseline and implemented location so another reviewer can reproduce your conclusion.
