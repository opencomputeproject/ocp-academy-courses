Choose class and depth first, then keep the selected implementation visible throughout the review. The two classes provide different widths and fixed riser opportunities. The depth designator summarizes a board choice, while the exact drawing supplies the actual dimensions.

Fixed features use the datum. Floating features use a board edge. That distinction explains how outlines can change while important interfaces remain consistent. A compatible system may still need a different tray, cables or other implementation details.

Finally, preserve the strength of every claim. A requirement, a recommendation and an example answer different questions. When a subject belongs to a companion specification or the complete product design, name that boundary and record the missing evidence. You'll use this discipline in the interface review.
