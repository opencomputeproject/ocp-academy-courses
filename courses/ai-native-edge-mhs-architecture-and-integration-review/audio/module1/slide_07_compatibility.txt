The common-chassis example aligns the board origins and places two Class N modules on a one hundred eighty-one millimeter pitch. It shows how Class N and Class L arrangements can share important interface positions. That pitch belongs to the arrangement being illustrated; it isn't a universal spacing rule for every system.

The chassis determines the maximum supported H P M depth. A shorter board may use a suitable tray to reach fixed chassis interlocks, while cables and other implementation choices change. Keep these system adaptations distinct from the board's own interface obligations.

Mechanical and electrical fit also don't establish logical plug-and-play behavior. Modular Plug-and-Play, or M P N P, addresses discovery and management interoperability. The companion specifications define such matters as platform infrastructure connectivity, high-speed interfaces and peripheral sideband behavior. The H P M Design Specification records the options selected for an actual product.

Write your handoff as a set of questions that can be answered with evidence. Which tray and retention arrangement is intended? Which connectors and cables are selected? What power can the system deliver? Which management baseline and discovery behavior are implemented? The shared form-factor architecture makes these questions more repeatable. It doesn't remove the need to answer them.
