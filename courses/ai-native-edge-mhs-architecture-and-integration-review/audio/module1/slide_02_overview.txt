# pronunciation: HPM -> H P M; MHS -> M H S; CCI -> C C I; KOZ -> keep out zone; DC-SCM -> D C S C M; CFF -> C F F; PCIe -> P C I Express; NIC -> Nick; HSIO -> high speed I O; PICPWR -> pick power; PCB -> P C B; M-PIC -> M Pick; M-XIO -> M X I O; M-PNP -> M P N P

This course follows three engineering decisions. First, choose a Host Processor Module class and depth that suit the intended system. Second, review the interfaces that constrain mounting, clearances, connectors and power. Third, turn your observations into findings that another engineer can reproduce.

The complete course takes about fifty-five minutes, including time to inspect diagrams and answer questions. The two review cases are guided desk exercises. You don't need a C A D workstation or a firmware development environment to complete them. Optional conference recordings and the related Academy courses are available for later study.
