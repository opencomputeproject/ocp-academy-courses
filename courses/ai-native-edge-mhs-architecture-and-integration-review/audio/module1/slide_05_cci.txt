# pronunciation: HPM -> H P M; MHS -> M H S; CCI -> C C I; KOZ -> keep out zone; DC-SCM -> D C S C M; CFF -> C F F; PCIe -> P C I Express; NIC -> Nick; HSIO -> high speed I O; PICPWR -> pick power; PCB -> P C B; M-PIC -> M Pick; M-XIO -> M X I O; M-PNP -> M P N P

A Common Chassis Interval, or C C I, is a planning point for the maximum H P M length that common system infrastructure can support. It isn't the overall length of the server. A chassis also needs room for its power, cooling, cabling and service structures.

The listed planning points are two hundred sixty, two hundred eighty, three hundred five, three hundred fifty and three hundred sixty-five millimeters. Choosing a board just beyond a supported boundary can reduce the set of systems it can address. The specification illustrates this with a board that grows beyond the infrastructure's supported interval.

An H P M designator combines the class letter with a length rounded down to the nearest millimeter. The outline tables show a three hundred five point five nine millimeter board using the N three-oh-five or L three-oh-five designator. Don't read the short name as a substitute for the exact dimensioned drawing.

For a review, record the actual board depth and the chassis's supported H P M depth separately. Then check the references that move with the board edge, the interfaces fixed to the datum, and the system items that consume the remaining space. The designator helps you organize that evidence; it doesn't replace it.
