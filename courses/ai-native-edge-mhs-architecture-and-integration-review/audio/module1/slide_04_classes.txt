Class N is the narrow form factor, with a fixed width of one hundred sixty-eight millimeters. Class L is the large form factor, with a fixed width of two hundred ninety-five millimeters. Both allow depths from two hundred fifty to three hundred sixty-five millimeters. The class defines width and a corresponding feature set; it doesn't select the processor or complete system configuration for you.

Class N is useful in single-node and dense multi-node arrangements. Class L provides a wider board area for single-node designs. These are intended use cases, not proof that a particular populated system will fit an enclosure. The source's overview illustrations show approximate subsystem regions. Read the dimensioned requirements when making an interface decision.

Class N supports two near-side fixed riser locations. Class L supports three. Full population of those locations isn't required. When a fixed riser is implemented, however, its connector, placement and power conditions apply. A board with fewer populated risers can therefore remain compliant while requiring more integration effort in a system designed around other options.

Compare width, depth and implemented features together. A matching class name answers the first part of a review. It doesn't answer the clearance, cabling, power or management questions that follow.
