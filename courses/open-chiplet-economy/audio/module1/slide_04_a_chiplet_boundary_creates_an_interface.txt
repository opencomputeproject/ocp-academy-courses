# pronunciation: O C P; O C E; F C S A; P H Y; die; chiplet; Bunch of Wires; U C I Express; C D X M L; A D K; M D K; T D K; D F T; I triple E.

A system on chip, or S O C, places many functions on one die. A chiplet approach implements selected functions on separate dies and combines them into a package. The boundary may separate compute from input and output, or divide a large compute function into repeatable tiles.

This creates freedom to choose a process for each function. It also creates new work. Communication that stayed on one die now crosses a physical interface. Power, clocks, reset, testing, and software must still behave as one system. A useful partition therefore starts with the required system behavior. It is not created by cutting a completed monolithic die into pieces.
