An open specification is valuable even when not every process node has an available implementation. A product team still needs a suitable physical interface on the chosen die technology. It also needs package and test capacity for the selected assembly.

Availability can change the architecture. A function that looks inexpensive on a mature node may need a different boundary if the required interface is unavailable there. A hub may need several physical interfaces, affecting area and power. Check those constraints with suppliers. Recent BoW Flexi work targets a simpler and more configurable design point, but a published specification should not be mistaken for a guaranteed catalog of qualified implementations.
