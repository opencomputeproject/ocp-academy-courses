# pronunciation: O C P; O C E; F C S A; P H Y; die; chiplet; Bunch of Wires; U C I Express; C D X M L; A D K; M D K; T D K; D F T; I triple E.

I triple E eighteen thirty-eight defines a test-access architecture for multi-die integrated circuits. Its purpose is to help tests reach dies and interconnections that may be buried in an assembled structure. It complements other test standards and the product's own test strategy.

Do not confuse that access architecture with the interface carrying normal functional traffic. A system still needs compatible functional protocols and separate evidence about fault coverage. Access makes a test possible; the patterns and observations determine what that test can detect.
