# pronunciation: O C P; O C E; F C S A; P H Y; die; chiplet; Bunch of Wires; U C I Express; C D X M L; A D K; M D K; T D K; D F T; I triple E.

A useful architecture decision can be reviewed by the next team. Record the workload, the functions on each die, and the traffic crossing each boundary. Include the package assumptions and the interfaces that must exist on the selected process nodes.

Then compare alternatives using the same requirements. Explain why one partition is preferred, where the margin comes from, and what remains uncertain. Reuse should be tied to a plausible family of products, rather than treated as an automatic saving. This decision record becomes an input to package planning, test planning, and eventually the system-level agreements studied in F C S A.
