Chiplet Data Exchange in X M L format, or C D X M L, provides structured information about a chiplet for integration and related workflows. Examples include geometry, interfaces, and electrical or mechanical attributes. The format helps tools consume information without repeatedly translating an informal document.

Using the same syntax does not guarantee that two descriptions mean the same thing. Units, coordinate systems, optional fields, and revisions must be understood. Refer to the applicable schema and documentation. Also distinguish the exchange format from the models it references. A description can identify a simulation capability without containing the supplier's entire proprietary simulation implementation.
