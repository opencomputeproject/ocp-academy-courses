# pronunciation: OCP = O C P; AI = A I; ORv3 = Open Rack version three; CDU = C D U
O C P work spans connected layers. Rack and Power addresses shared rack and power interfaces. Cooling Environments addresses thermal technologies. Server and Networking projects focus on computing and connectivity. Data Center Facility work considers the infrastructure around the equipment. Hardware Management, security, firmware, and sustainability work add capabilities that cross these layers. The online community directory is the current map. Use the problem you want to solve to find the right group, rather than assuming every topic belongs to the rack project.
