# pronunciation: OCP = O C P; AI = A I; ORv3 = Open Rack version three; CDU = C D U
O C P began in 2011, following work to improve the efficiency of Facebook’s growing computing infrastructure. Facebook, now Meta, opened designs and helped launch the project with other founding participants. The original challenge was scaling internet services efficiently. Today’s A I workloads create additional demands, but they did not cause the project’s founding. The lasting idea is to share useful design work so more organizations can examine it, adapt it under its license, and improve it together.
