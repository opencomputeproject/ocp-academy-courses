The B M C needs a reliable way to learn where register spaces live. A memory-map directory can provide a pointer and size for each space and each IP block. The specification also permits JSON-based description alternatives.

Directory entries other than the self-description location may be optional when the JSON supplies the register locations. If the full description isn't available, an entry pointing to statically mapped internal JSON with minimum viable contents is required. If JSON is supplied as an addendum to the P D image, the directory itself is optional.

When a directory is used, its offset-plus-size ranges must not overlap and its values are big-endian. The specification's illustrated offsets are not addresses every implementation must copy. And the access examples don't imply that an I squared C or I cubed C mailbox is always present. The discovery mechanism and implemented access path must be documented together.
