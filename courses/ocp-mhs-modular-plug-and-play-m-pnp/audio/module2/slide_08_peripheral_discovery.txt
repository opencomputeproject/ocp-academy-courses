The package contains eight peripheral JSON examples. Five cover riser variants, including one-slot and two-slot arrangements and a one-slot, eight-lane riser with an I squared C expander.

The remaining examples are a Universal Backplane Management, or U B M, backplane; a Type two Power Distribution Board, or P D B; and a P C I E switch board with four sixteen-lane slots. The specification covers further peripheral classes, so these examples are a teaching set rather than an exhaustive list.

The peripheral examples supplied with this course declare the hardware-component schema at version zero point seven point three. Distinguish that schema declaration from each example file's version, and check schema compatibility before using an example in a design.
