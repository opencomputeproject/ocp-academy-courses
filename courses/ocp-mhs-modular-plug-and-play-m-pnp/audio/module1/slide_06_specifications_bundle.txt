The release package contains three specification files, twenty-five supplementary files, and a reed me file. Fru, Discovery and Boot is version zero point seven point zero, release candidate one, with one hundred thirty-six PDF pages. H P M and Peripheral Programmable Device is the same specification version, with three hundred thirty-eight pages. Interoperability is version zero point three point zero.

A Fru is a field replaceable unit. A P D is a programmable device; an FPGA, or field-programmable gate array, is one implementation rather than the only implementation covered.

The supporting material contains two schemas, four schema documentation PDFs, eleven JSON mockups, seven Visio drawings, and an IP block examples workbook. The schemas are hardware-component version zero point seven point three and programmable-device version zero point seven point two.
