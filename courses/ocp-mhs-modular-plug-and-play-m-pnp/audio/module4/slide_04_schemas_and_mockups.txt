The package provides two schemas and four documentation PDFs: a developer guide and a documentation guide for each schema. There are eleven JSON mockups in total. One describes the H P M Fru. Two describe programmable devices: a primary H P M example and a peripheral C P L D example. Eight describe peripherals.

Those peripherals include five riser variants, a U B M backplane, a Type two P D B and a P C I E switch board. Seven Visio files support the worked examples.

The hardware examples supplied with this course use hardware-component version zero point seven point three. The two P D examples declare programmable-device version zero point seven point two. Keep those schema versions separate from the individual example file versions, and verify compatibility before relying on an example in an implementation.
