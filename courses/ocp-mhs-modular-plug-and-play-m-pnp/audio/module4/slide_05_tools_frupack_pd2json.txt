Useful tools are available, but their existence and their compatibility with this release are separate facts. The Fru tool repository provides FRUPack dot py for packaging Fru information. The M-PNP JSON validation repository provides schema and interconnection analysis. Its documented Draft four and version zero point five provenance mean that version zero point seven compatibility needs testing.

The IP Block Examples List version two lists L T P I and M-PESTI IP references. Those are useful starting points, not proof that a particular platform is conformant.

For every tool you use, record the exact repository revision, inputs and results. That makes a compatibility claim reproducible.
