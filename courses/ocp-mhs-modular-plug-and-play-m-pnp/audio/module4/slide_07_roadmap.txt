A reproducible M-PNP implementation starts with a documented specification baseline. Record the version zero point seven release package and the exact document identifiers used by your design. The Fru, Discovery and Boot and H P M and Peripheral Programmable Device specifications are version zero point seven point zero, release candidate one. The Interoperability specification is version zero point three point zero.

Document versions, schema versions and example file versions are separate. Record each rather than treating the release package number as a shared version for every file.

Use the linked specifications when checking a requirement, and record the relevant section or page in your implementation notes. That makes it possible for another engineer to reproduce a result against the same requirements.
