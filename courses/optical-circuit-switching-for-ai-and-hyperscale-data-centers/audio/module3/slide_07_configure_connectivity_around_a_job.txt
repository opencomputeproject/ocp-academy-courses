# pronunciation: OCS -> O C S; EPS -> E P S; OEO -> O E O; TPUv4 -> T P U version four; GPU -> G P U; GPUs -> G P Yous; ACTINA -> Actina; MoE -> M O E; OCS-BCube -> O C S B Cube; gNMI -> g N M I
A fixed physical network constrains every job to the same topology. Configurable Cube-to-Cube connectivity gives the controller another option: select a topology that fits the allocated resources and communication pattern. A three-dimensional torus is one important example in the T P U architecture.

This is a physical connectivity decision, coordinated with job placement and system operation. It should not be confused with inspecting and rerouting every packet in the optical switch. Nor does the example imply arbitrary instantaneous topology changes while traffic is active. The controller must respect the available ports, permitted paths, optical conditions and transition process. The value comes from making the physical fabric a resource the system can configure deliberately.
