# pronunciation: AICC -> "A I C C"; AI -> "A I"; OCP -> "O C P"
Module two. Open infrastructure across the continuum.

A I C C is a hardware-focused O C P project. Its challenge is to carry the benefits of open, modular infrastructure into environments that differ far more than conventional hyperscale deployments.

In this module, we'll connect the project's five current domains to the physical constraints of real sites. We'll also follow an inference request beneath the application layer. That view will show why compute, memory, storage, networking, telemetry, and trust must work as a system.

The goal is not one universal platform. It is a reusable toolkit of interfaces, building blocks, and solution patterns that can support meaningful software choice.
