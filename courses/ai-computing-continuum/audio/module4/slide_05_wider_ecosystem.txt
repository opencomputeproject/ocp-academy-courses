# pronunciation: AICC -> "A I C C"; AI -> "A I"; OCP -> "O C P"; MHS -> "M H S"; RAS -> "R A S"
A I C C should connect existing open-infrastructure work rather than recreate it.

Within the project, current public subprojects include A I Native Wireless Access and A I Native Edge M H S. They provide concrete starting points for radio environments and modular edge hardware.

Across O C P, Open Cluster Designs for A I addresses repeatable cluster and pod architectures. A I Hardware-Software Co-Design explores resource discovery, composability, topology awareness, and efficient use of heterogeneous systems. Data Center Telemetry provides information needed for health, power, cooling, and operational decisions.

O C P Sustainability contributes lifecycle measurement, circularity, and efficiency practices. Accelerator reliability, availability, and serviceability work addresses error reporting, fault behavior, and silent data corruption. Open chiplet initiatives bring specialization and composability down to the package level.

A I C C's distinctive role is the connective tissue across hyperscale-adjacent environments and across distance. It can define requirements and handoffs that let those existing building blocks participate in a continuum.

The project page and wiki provide the current scope, charter, mailing list, and meeting information. Contributors can bring a use case, an interface proposal, a design contribution, validation data, or a requirement that reveals a gap between projects.
