# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
O equipamento de armazenamento é organizado em torno das informações que deve conter e como deve ser acessado. NVME, abreviação de Non-Volatile Memory Express, define como o software host se comunica com a memória não volátil. Os gabinetes compatíveis oferecem acesso rápido ao armazenamento de estado sólido. Os servidores focados na capacidade podem fornecer muitas posições de unidade para grandes conjuntos de dados, backup ou arquivamentos.

O layout ilustrado inclui um gabinete de compartimento alto de 4U ou mais. Esse é um exemplo de design, não uma regra para todos os sistemas de armazenamento. Compare a capacidade, o desempenho de acesso, as interfaces, as necessidades de proteção e de serviço, em vez de escolher apenas pela altura.
