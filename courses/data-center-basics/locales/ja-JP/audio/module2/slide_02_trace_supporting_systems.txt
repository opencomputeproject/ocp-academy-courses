# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
このモジュールを完了すると、従来の電力経路を追跡し、バックアップ システムの目的を説明し、冷却によって装置から熱がどのように除去されるかを説明できるようになります。また、ホットと コールドアイル アイルコンテインメント を比較し、空きフロア スペースが別のワークロードのためのスペースを保証しない理由を認識します。

目標はシステム ビューです。デプロイメントは、サポートするシステムが同時に対応できる場合にのみ機能します。
