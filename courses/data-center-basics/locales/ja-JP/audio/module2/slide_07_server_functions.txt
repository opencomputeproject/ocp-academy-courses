# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
交流ACと直流DCは電流の種類を示す言葉であり、変換する場所を決めるものではありません。多くのハイパースケール環境やOpen Rackでは、ラックの電源シェルフで変換を集約します。モジュラー整流器が入力ACをDCに変換します。Open Rackバージョン3の例では、公称48ボルトのDCバスバーをラック背面に配置します。

バスバーは電力を分配する導体であり、変換を行う装置ではありません。対応するサーバーを差し込むと、ブラインドメイト接点が接続されます。その後、機器内のDC-DC電圧調整によって、各部品が必要とする低い電圧を生成します。

この構成では、サーバーごとの電源コードを減らし、設置と前面からの保守を簡素化して、複数の機器で整流器容量を共有できます。適切な運転負荷では、使い切れない余剰容量を減らし、利用率と変換効率を改善できる場合があります。同じ電力と導体抵抗なら、配電電圧を高くすることで、低い電圧のDC配電より電流と抵抗損失を減らせます。

従来のAC給電ラックでは、各サーバーの電源ユニットにACを送り、そこでDCに変換します。どちらの構成も使われています。電圧、コネクター、容量、冗長性の設計を確認してください。バスバーだけで効率や可用性が保証されるわけではありません。
