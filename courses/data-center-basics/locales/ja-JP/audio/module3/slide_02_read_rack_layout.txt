# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
このモジュールを完了すると、ラックの幅と垂直の ラックユニット を区別し、一般的なコンピューティングとストレージの配置を認識し、電源、冷却、ケーブル配線、アクセスがレイアウトを形成する理由を説明できるようになります。

Open Rack がどのように異なる機械システムを使用しているかもわかります。このモジュールでは語彙を紹介します。 OCP コースの概要では、より広範なアーキテクチャとコミュニティのコンテキストを提供します。ラック設計、機械的インターフェイス、および電力供給についてさらに詳しく見るには、OCP Academy の Open Rack コース シリーズを続けてください。
