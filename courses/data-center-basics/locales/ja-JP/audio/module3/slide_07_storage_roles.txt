# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
ストレージ機器は、保持する必要がある情報とそのアクセス方法に基づいて編成されています。 NVME は Non-Volatile Memory Express の略で、ホスト ソフトウェアが不揮発性メモリと通信する方法を定義します。互換性のあるエンクロージャは、ソリッドステート ストレージへの高速アクセスをサポートします。容量を重視したサーバーは、大規模なデータセット、バックアップ、またはアーカイブ用に多くのドライブ位置を提供できます。

図示のレイアウトには、4U 以上のハイベイ エンクロージャが含まれています。これは 1 つの設計例であり、すべてのストレージ システムに適用されるルールではありません。高さだけで選ぶのではなく、容量、アクセス パフォーマンス、インターフェイス、保護、サービスのニーズを比較してください。
