# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
このコースは、4 つの関連した質問に従います。 データセンター は何をしますか?何が機器の稼働を維持しているのでしょうか?その機器はどのようにラックに収まりますか?そして、人々はシステム全体をどのように運用し、改善するのでしょうか?

これらの質問を 4 つのモジュールで解決します。短いナレーションによる説明が概念を結び付け、ビデオで長い例が提供されます。知識チェックによりフィードバックが得られ、再試行する機会が与えられます。これらのモジュールを組み合わせることで、Open Compute Project がインフラストラクチャへの共有アプローチをどのように開発するかを検討することができます。
