# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
Los cuatro niveles de Uptime Institute describen las capacidades de infraestructura del sitio. El nivel uno proporciona capacidad básica. El nivel dos agrega componentes de capacidad redundantes. El nivel tres agrega mantenibilidad concurrente: el trabajo planificado puede eliminar un componente o una ruta de distribución sin interrumpir las operaciones. El nivel cuatro agrega tolerancia a fallos para una falla de equipo individual o una interrupción de la distribución.

Estas categorías no prometen un porcentaje de tiempo de actividad anual particular. Tampoco reemplazan las aplicaciones resilientes, el diseño de redes ni las operaciones disciplinadas. Utilice la descripción del nivel para preguntar qué mantenimiento y fallas puede soportar la infraestructura y luego considere los requisitos más amplios del servicio.
