# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
La entrega de energía y extracción de calor son partes conectadas de un sistema. Las fuentes de respaldo y el almacenamiento de energía tienen diferentes funciones. La separación del flujo de aire ayuda a que el enfriamiento funcione trabajo computacional útil, y refrigeración líquida agrega otra vía para mover el calor.

El espacio libre es sólo una parte de la capacidad de implementación. Antes de cambiar el equipo, considere en conjunto la entrega eléctrica, las condiciones térmicas, la conectividad y el acceso al servicio. Esa visión del sistema es la base para comprender lo que sucede dentro de un bastidor.
