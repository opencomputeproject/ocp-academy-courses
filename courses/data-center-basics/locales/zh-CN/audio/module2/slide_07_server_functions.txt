# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
交流AC和直流DC描述的是电流类型，并不决定电能转换必须在哪里进行。在许多超大规模数据中心和Open Rack部署中，转换集中在机架电源框内进行。模块化整流器将输入的AC转换为DC。以Open Rack第3版为例，标称48伏的DC母排沿机架后部布置。

母排是用于分配电力的导体，本身不执行电能转换。兼容的服务器推入机架时，通过盲插触点接通电源。设备内部随后通过DC-DC稳压，产生各部件所需的较低电压。

这种架构省去了每台服务器单独的电源线，简化了安装和前侧维护，并让多台设备共享整流器容量。在适当的运行负载下，这有助于减少闲置且无法利用的容量，提高容量利用率和转换效率。在功率和导体电阻相同的条件下，提高配电电压，也能比低压DC配电减少电流和电阻损耗。

传统的AC供电机架仍会把AC送到每台服务器自身的电源，再在那里转换为DC。两种架构都在使用。应检查电压、连接器、容量和冗余设计；仅有母排并不能保证效率或可用性。
