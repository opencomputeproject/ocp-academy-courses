# Localized narration. Standard Latin acronyms retained; decimal values use native spoken forms.
存储设备是围绕它必须保存的信息以及如何访问它来组织的。 NVME 是 Non-Volatile Memory Express 的缩写，定义了主机软件如何与非易失性内存进行通信。兼容的机柜支持快速访问固态存储。以容量为中心的服务器可以为大型数据集、备份或存档提供许多驱动器位置。

所示布局包括 4U 或更大的高棚机柜。这是一个设计示例，并不是每个存储系统的规则。比较容量、访问性能、接口、保护和服务需求，而不是仅根据高度进行选择。
